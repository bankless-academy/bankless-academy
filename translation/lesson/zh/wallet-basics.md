钱包有点像你熟悉的 `Web2` 互联网账户。你会用钱包登录区块链生态，也就是 `Web3`，在这里使用`加密货币`，连接各种`区块链应用`！

# 钱包的定义

加密钱包到底是什么？

简短的定义是：它是`区块链`上的一个账户，用来存放数字资产、登录区块链应用。

它就像你在互联网上的私人保险箱，而唯一的钥匙在你手里。同时，这个保险箱也很像普通的网站账户：你可以用它购物、收发`加密货币`，以及与区块链交互。

但和你熟悉的 `Web2` 账户不同，一个钱包就能访问整条区块链，以及大量区块链应用。这相当于用一个账户走遍整个互联网。

![](https://app.banklessacademy.com/images/wallet-basics/wallet-definition-d2912914.svg)

# 创建钱包难吗？

以前确实不容易，但如今任何人都能相当轻松地创建钱包。

如果你会在电脑上下载安装软件（或在手机上装应用），那么创建第一个钱包对你来说不成问题。

管理钱包更棘手的部分是保证它的安全，我们马上就会讲到！

挑选`钱包应用`可能也让人有点犯难。它就是你装在设备上、用来访问区块链钱包的那个应用。我们建议从 Zerion 钱包应用开始：它对新手友好，支持很多主流区块链。等你在 `Web3` 里更自在之后，多半还会尝试其他服务商，创建多个钱包。

# 钱包与密码找回

关于 `Web3` 钱包，有一点最需要理解：
**这里没有「重置密码」，也没有「修改密码」**。

我们大多数人都习惯了这些功能。忘了密码，点几下按钮，就能换一个新的。很简单。

加密钱包不是这样。由于区块链的运作方式，钱包在创建时会被分配一个「地址」和一串复杂的「密码」，这两样都不是你自己选的。

这组地址和密码无法更改，不过你随时可以创建新钱包。有些较新的钱包提供了找回功能，但永远不要依赖它。下面我们就来了解这些特殊的地址和密码，好让你用得放心！

# 钱包的公钥

钱包的`地址`由它的`公钥`生成。你可以把地址当成用户名：它通常看起来像一串随机的字母和数字。

例如：_0xe1887fF140BfA9D3b45D0B2077b7471124acD242_

借助一些 `Web3` 服务，你可以给它起一个更好记的名字，不过那是另一课的内容了。

你也可以把地址想成住址。它是公开的，谁都能看到，它告诉别人可以把加密资产发到哪里，同时不会泄露你的任何个人信息。

分享钱包**地址**是完全安全的。

**注意**：一个钱包应用可以保存多组公钥和`私钥`。

![](https://app.banklessacademy.com/images/wallet-basics/your-wallets-public-key-87828c3e.svg)

# 钱包的私钥

如果地址像住址，那么`私钥`就像大门钥匙。它是你资金和资产的「密码」。

例如：_eceac283e04f121cbd40b69e16ab9dec0220df80bf092a4c72b53e69cf74d215_

**分享这把钥匙永远不安全：你可能因此失去钱包和里面的一切。**

多数人建议你连数字副本都不要保存。谁拿到私钥，谁就拿到了`钱包`里的一切。

它不只是一个密码。一旦失去它，你无法重置。

好在大多数`区块链应用`不会要求你每次转账或签署区块链交易时都输入这一长串字符。私钥通常在后台悄悄工作。

![](https://app.banklessacademy.com/images/wallet-basics/your-wallets-private-key-0d84ad39.svg)

# 助记词

设置新钱包时，钱包应用会给你一组`助记词`。

它也叫「种子短语」或「秘密短语」。在下面这些情况下，这串词可以帮你重新访问钱包和加密资产：

- 你的`钱包应用`或设备突然故障或损坏。
- 设备丢失或被盗。
- 你想在多台设备上访问同一个钱包。

大多数助记词由 12 到 24 个单词组成，代表一段独一无二的数据。这段数据用来生成钱包的`公钥`和`私钥`。

钱包恢复**不会**更改或重置密钥。

助记词就像一把主钥匙：它能重新生成钱包里的每一组密钥对。**永远不要分享你的助记词。**

![](https://app.banklessacademy.com/images/wallet-basics/recovery-phrase-c614c36c.svg)

# 钱包的类型

就像电脑软件有很多种，钱包也有很多种。我们来看四大类：

- 🏦 **托管钱包**：由第三方负责保管你的私钥。
- 👤 **自我托管（非托管）钱包**：由你自己负责保管私钥。

`自我托管钱包`又分成两种风格：

- 🔥 **热钱包**：运行在电脑或手机上的软件。
- 🧊 **冷钱包**：一个硬件设备（类似 U 盘），你把它放在安全的地方。

你可能还会听说`智能钱包`：一种新兴类型，它能运行代码，从而支持通行密钥登录、账户找回等附加功能。

每种钱包适合不同的场景。别担心，今天我们只创建一个钱包。

![](https://app.banklessacademy.com/images/wallet-basics/types-of-wallet-094f0eb1.png)

# 托管钱包

`私钥`是打开你`钱包`的钥匙，所以保管好它非常重要！

提供`托管钱包`服务的包括 Coinbase、Kraken 这类加密货币交易所。**它们是你的钱包托管方**：替你保管私钥。你像使用普通网站一样使用它们的服务（邮箱登录，密码可重置）。

对有些人来说这就够用了，但这要求你信任这些第三方：相信它们能保护好你的加密资产，并在你想交易或转出时给你放行。此外，你能访问的`区块链应用`可能也会受限。

![](https://app.banklessacademy.com/images/wallet-basics/custodial-wallets-4eede755.svg)

# 非托管钱包

`自我托管钱包`（例如 Zerion 或 Trezor）意味着你完全掌控自己的`私钥`。这里**没有托管方**，保管私钥的责任全在你一个人身上。

在 `Web3` 世界里，这类钱包提供最广的访问范围和最大的自由。你不必担心第三方冻结或错误处理你的资金。

代价是风险：如果你弄丢了`助记词`，或者私钥被泄露，往往几乎没有办法再恢复对钱包的访问。

不管你选哪条路，熟悉并习惯钱包安全都很值得。在这一课结束之前，我们会给你一些建议。

# 热钱包

在 `Web3` 里，你会经常听到「热钱包」和「冷钱包」这两个词。

`热钱包`是通过设备上的应用访问的钱包，比如 Zerion 应用。和很多 `Web2` 应用一样，钱包应用始终连着互联网。

你的`私钥`被加密后保存在钱包应用里，只有在你与区块链交互时才会被调用。正是因为互联网和私钥之间这种「热」连接，它们才被叫作热钱包。

热钱包适合日常的小额操作，就像你放在口袋里的实体钱包。今天我们要创建的就是热钱包！

![](https://app.banklessacademy.com/images/wallet-basics/hot-wallets-9356886d.svg)

# 冷钱包

随着你在 `Web3` 之路上走得更远，你会看到一个充满有趣技术取舍的世界。

`冷钱包`用便利性换来更高的安全性。冷钱包把你的`私钥`保存在专用硬件设备上（比如 U 盘或移动硬盘）。你必须把硬件钱包实际连接到电脑，才能访问区块链上的钱包。私钥从不直接连接互联网，冷钱包的名字正来自这种「冷」连接。

人们普遍认为冷钱包比`热钱包`更安全，因为`私钥`离线保存，数字攻击者够不着。

Ledger 和 Trezor 就是`冷钱包`的例子。

![](https://app.banklessacademy.com/images/wallet-basics/cold-wallets-0e3183d1.svg)

# 钱包安全

无论你的`自我托管钱包`是热钱包还是冷钱包，都应该养成一些聪明的安全习惯。

🖊️ 把`助记词`记录在耐久的实体材料上（覆膜纸，甚至钢板），存放在非常安全的地方。永远不要把它或你的`私钥`告诉任何人。**它不只是一个密码。**

🔍 每次转账或签名都要仔细核对细节，哪怕金额很小：操作无法撤销。

🔭 在连接钱包或签署交易之前，先研究你打算使用的`区块链应用`。

💰 用只放少量资金的钱包去尝试新事物、探索 Web3，并考虑把高价值资产分散在多个钱包账户里。
