# 货币简史

从最早的时代起，货币就是社会的重要组成部分：人们用珠子、贝壳和石头交换商品与服务。

但早期货币有个问题：新的货币太容易被找到或造出来。一样东西越多，价值就越低，于是每个人手里的钱会慢慢变得不值钱。货币要守住价值，就必须更难获得。

后来人们采用黄金和白银来解决这个问题。它们的关键优势在于稀缺：供应不是无限的，谁都很难大幅增加流通中的货币量。这种`稀缺性`帮助货币保住了价值。

随着社会发展，政府的中央银行开始发行标准化的金银铸币。这样的货币既好辨认又好计量，也是可靠的价值储存手段。

![](https://app.banklessacademy.com/images/bitcoin-basics/a-brief-history-of-money-b5126abd.svg)

# 货币简史（第二部分）

纸币出现后，各国货币改由黄金「背书」。货币的价值直接对应仓库里存放的一定数量的贵金属。

到了 20 世纪，这套「`金本位`」倒下了。

贵金属逐步与世界各国的货币脱钩，好让一国经济能突破本国黄金储备的限制继续增长。中央银行不再需要黄金就能创造货币，可以按本国经济的需要发行任意数量的新钱。牢牢掌握货币供应量，也就掌握了货币的价值。

进入数字时代，电子货币已大量取代实体货币。把钱存在商业银行里，让我们用上了信用卡和支付软件。这既方便又安全，但也把营利性企业塞进了我们和自己的钱之间。

![](https://app.banklessacademy.com/images/bitcoin-basics/a-brief-history-of-money-part-2-3f9be5ac.svg)

# 问题所在

当今金融体系的问题在于：我们对自己的钱缺乏控制权，这削弱了我们自由决定存多少、花多少的能力。

`中央银行`管理着一国的`货币政策`，可以随意投放新的货币。缺少`稀缺性`，往往让我们的钱一年比一年不值钱。价值不可预测、不断下滑的货币，会逼着我们把它花掉：**「反正我的钱每年都在贬值，为什么还要存？不如现在就花了。」** 💸

`商业银行`是我们日常存钱和花钱的地方，它同样影响着我们的消费习惯。作为`托管方`，它可以拦下交易，也可以扣押我们的资金。有些银行甚至禁止客户购买加密货币！**如果银行随时能冻结你一辈子的积蓄……你真的拥有自己的钱吗？** 💸

---

货币要重新支撑财务自由，就必须找回两个逐渐失去的关键属性：

- 💎 **价值：** 货币必须能长期可靠地储存价值。
- ✊ **所有权：** 货币必须便于我们自己保管和保护。

只有具备这些特质，我们才能重新自由地储蓄和消费。

# 比特币登场

`中本聪`认为，货币太重要了，不该由少数人控制。他们想创造一种对所有人都公平、可靠的货币。

比特币（`BTC`）由此诞生：一种运行在传统银行体系之外的数字货币。

- ⛓️ 它是`点对点`的：直接把人和人连起来。靠`区块链技术`自动运行，不需要机构代为保管或处理交易。支持者称它是「一套没有统治者的规则」。
- 💎 它是`稀缺`的：没有中央银行无限增发，比特币的货币政策稳定可预测，尊重长期储蓄。
- ✊ 它是`自我托管`的：不需要机构托管转账或资产。网络记录谁拥有什么，你的`私钥`来证明：只有持钥人才能动这些币。

凭借这些特质，比特币赢得了「数字黄金」的称号。

![](https://app.banklessacademy.com/images/bitcoin-basics/enter-bitcoin-b108517c.svg)

# 数字黄金：稀缺性

📉 你是否觉得越来越难跟上上涨的物价？

比特币的稀缺性指的是它有数量上限：最多只会有 2100 万枚。这个`最大供应量`写在代码里，让比特币像黄金一样稀有。

新币仍会通过一个费力的过程进入`流通供应量`，这个过程叫`加密货币挖矿`。大约每四年，新币的发行量就会`减半`，随着接近上限逐渐趋向于零，因此矿工会越来越依赖交易手续费。

比特币固定的`货币政策`让它适合长期保值。自 2024 年起，受监管的基金（`现货 ETF`）让传统投资者也能持有比特币，强化了它「数字黄金」的角色。

由于市场投机，它的短期价值依然波动剧烈。

![](https://app.banklessacademy.com/images/bitcoin-basics/digital-gold-scarcity-8c8905f7.svg)

# 比特币网络

我们换个角度，看看比特币背后的引擎：
**比特币网络**。

比特币运行在一个共享网络上，由全球成千上万台计算机共同承载。网络中的每一台计算机都参与维持它的运转，网络正是由这些计算机构成的！如果某一台处理了一笔欺诈交易，其他计算机会纠正它。

这也意味着黑客攻击时没有单一的施压点。要控制这个网络，就得攻陷其中的大多数计算机。

这种防御策略叫`去中心化`：把控制权从一个中心团体转移到许多小团体手中。正是它让加密货币网络几乎无法被叫停。

![](https://app.banklessacademy.com/images/bitcoin-basics/the-bitcoin-network-eda52e60.svg)

# 比特币挖矿

比特币网络没有中央银行，只能依靠`去中心化`的参与者。这些参与者被称为`矿工`，他们不断检查交易，并把交易写进一个「数据库」：`区块链`。

矿工必须有动力保持活跃和诚实，才能保护网络不受欺诈。他们会频繁复核彼此的结果，同时也因为付出的工作而获得回报。我们提交比特币交易时，会付一小笔手续费给打包这笔交易的矿工。矿工还会赚到新的比特币，也就是「区块奖励」。

这些奖励让比特币的`流通供应量`在 2100 万 `BTC` 的`最大供应量`上限内缓慢增加。

正是这种缓慢、可预测的新币投放，把比特币和传统货币区分开来。一切都由社区认可的计算机代码（「没有统治者的规则」）和去中心化的参与者管理，而不是`中央银行`里的一小群人。

![](https://app.banklessacademy.com/images/bitcoin-basics/bitcoin-mining-9b8a77ea.svg)

# 发送一笔比特币交易

要弄懂驱动比特币交易和挖矿的确切机制，会相当复杂。不过，使用和发送比特币其实很简单！

今天我们只看一个简化的流程：

1. 你用自己的`加密货币钱包`提交一笔交易，向朋友的钱包地址发送 0.1 `BTC`。
2. 一位矿工检查你的交易有没有错误，其他矿工再复核结果。
3. 通过后，你的交易被写入`区块链`「数据库」。
4. 你的朋友在钱包里收到 0.1 BTC。

# 货币的革新
