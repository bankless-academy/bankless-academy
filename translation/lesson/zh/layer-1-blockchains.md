# 简介

当想使用某条`区块链`网络的用户超出它的承载能力时，问题就来了。对`区块空间`的大量需求可能只是一阵子，也可能只要用户仍然强烈想用这条链就一直存在。需求高企时，用户会相互抬价，让自己的交易更快被处理，费用随之上涨，资金较少的用户被挤出局。

这一课会讲清楚：为什么以太坊和其他区块链都受制于`区块链三难困境`，这个困境如何导致上面这些问题，以及它如何影响以太坊服务全体用户的计划。我们还会看看几条区块链在三难困境面前做出的取舍，以及这些取舍对 Academy 探索者意味着什么。

![](https://app.banklessacademy.com/images/layer-1-blockchains/introduction-feee7790.svg)

# 区块链三难困境

正如「三难」这个词所暗示的，区块链有三种彼此竞争的特性，无法同时把三者都做到最好。

它们是：`安全性`、`可扩展性`和`去中心化`。

一条区块链若要成为全球规模货币体系的中立基础，这三方面都得出色。货币体系需要安全，不受欺诈侵害；需要去中心化，不被审查者攻击；还需要可扩展，才能满足全球社会 80 多亿人的需求。

![](https://app.banklessacademy.com/images/layer-1-blockchains/blockchain-trilemma-9bd1b1e4.svg)

# 安全与共识

安全性是公共区块链最基础的要求。网络（比如区块链网络）中的计算机必须就「究竟发生过哪些交易」达成一致，才能协同工作，这种一致就叫`共识`。如果攻击者无法破坏网络对这个事实的一致意见，这条区块链就是安全的。共识算法正是为抵御这类攻击而设计的。

像比特币这样使用`工作量证明`共识的链，通过让区块生产变得高度竞争来保护这种一致：每个区块生产者都抢着解一道数学题。最先解出的人赢得创建下一个区块的权利，以及随之而来的`区块奖励`。要改写链上近期的历史，需要在算力和能源上投入巨资，攻击者花掉的多半会超过所得。

![](https://app.banklessacademy.com/images/layer-1-blockchains/security-and-consensus-4e857c50.svg)

# 安全与攻击

对区块链共识的一种可能攻击是`51% 攻击`：攻击者掌握了网络中大多数共识力量，就能回滚近期交易、把同一笔币花两次，或者审查新交易。他们无法伪造签名，也无法花别人的钱。这里的「多数」，在工作量证明里指 51% 的算力，在权益证明里指 51% 的`质押`，都是极其庞大的资本投入。而在权益证明中，可被证明的作弊行为（比如为两个相互冲突的区块签名）会导致质押被销毁，这叫`罚没`，攻击者的损失多半超过所得。

在`权益证明`共识里，区块生产者不是通过竞争选出，而是随机指定的。和工作量证明一样，共识算法确保任何单一实体都无法经常「赢得」创建新`区块`的权利。

![](https://app.banklessacademy.com/images/layer-1-blockchains/security-and-attacks-a73febc0.svg)

# 可扩展性：吞吐量

`可扩展性`指的是一条区块链快速处理大量交易的能力。它由两部分决定：吞吐量和最终性。

1）`交易吞吐量`：区块链一次能处理多少交易，通常用每秒交易数（`TPS`）来衡量。

想象很多人在公交站等车，每分钟还有人不断到来，大家都想出行。但一辆车能坐的人是有限的。想让站台更快清空，要么换更大的车（装更多人），要么让车来得更勤（间隔更短）。往每个区块有限的`区块空间`里塞进大量交易，道理是一样的。你可以在 [https://txstreet.com/v/eth-btc](https://txstreet.com/v/eth-btc) 看到带实时数据的可视化。

![](https://app.banklessacademy.com/images/layer-1-blockchains/scalability-throughput-d36672c5.svg)

# 可扩展性：最终性

区块链可扩展性的第二个方面是：

2）`最终性`：我们什么时候可以比较有把握地认为一笔交易不会被更改或回滚？

在比特币这样的工作量证明链上，最终性以区块数衡量：你的交易之后追加的区块越多，你就越能确信它不会被回滚。别忘了，安全的共识算法让修改过去的区块变得非常昂贵，而且越往前改代价越高。比特币大约每 10 分钟产出一个新`区块`，所以等待若干次确认大约需要一小时。以太坊的权益证明走了另一条路：`验证者`投票敲定区块，大约 13 分钟（两个`时段`的投票）之后，一笔交易就是最终的了。

![](https://app.banklessacademy.com/images/layer-1-blockchains/scalability-finality-73177220.svg)

# 去中心化分散权力

`去中心化`是区块链三难困境的最后一根支柱：把控制权和决策权从单一实体转移到由许多参与者组成的分布式网络。正是去中心化这一根本原则，让区块链得以`无需许可`和`抗审查`：任何人都能使用去中心化区块链，任何人都能基于它们开发软件。

像 Facebook 和 Twitter 这样的中心化平台，可以随时停用任何人的账号。Twitch 或 TikTok 上不少有影响力的主播都曾无故被平台下架。即便社交媒体用户能把账号恢复过来，过程也可能漫长而痛苦。没有去中心化，区块链`账本`不过是银行电脑里的一张财务表格，由银行家决定谁可以开户。`无需许可`的网络意味着权力足够分散，没有任何办法能剥夺某个人或实体的访问权。

![](https://app.banklessacademy.com/images/layer-1-blockchains/decentralization-distributes-power-feafb05a.svg)

# 它去中心化吗？

不过，某样东西是否去中心化，并不是简单的是或否。10 个控制实体算去中心化吗？1000 个呢？100 万个呢？「足够去中心化」并没有统一的标准线，所以把去中心化看成一个光谱更合理。除了非黑即白，中间还有许多灰度。

于是我们可以说某样东西「比另一样更去中心化或更不去中心化」，而不是简单地说「中心化还是去中心化」。要让一个中立的货币体系抵御国家层面的审查，就需要很高的去中心化程度。较新的区块链常常用去中心化换取可扩展性，但这也让它们暴露在社会和政府的同样压力之下，就像完全中心化的平台那样。它们最终可能做出与中心化社交网络一样的审查行为。

![](https://app.banklessacademy.com/images/layer-1-blockchains/is-it-decentralized-9cd381fb.svg)

# 一些例子

每条区块链都有自己应对三难困境的方式，也都为聚焦自身目标做了取舍。比特币和以太坊把安全性和去中心化排在可扩展性之前，代价是比特币的`最终确定时间`很长，以太坊的`区块空间`很有限。当使用`智能合约`的需求激增，尤其是 DeFi 相关需求时，以太坊的费用就会上涨；在 2021 年的需求高峰，一笔交易可能要花几十美元。

费用上涨给 BNB Chain 这类`替代性 Layer 1` 留出了空间，它们用去中心化换取可扩展性，以获得更高的`交易吞吐量`和更低的费用。Solana 这样的第三代链用新方法来解三难困境，但所有区块链仍然受制于这些基本约束。每条链的选择，都会通过随之而来的基础性影响塑造出它自己的生态。

![](https://app.banklessacademy.com/images/layer-1-blockchains/some-examples-30020a8d.svg)

# 那能做些什么？

既然以太坊把高安全性和高去中心化放在首位，它又该如何扩展，成为它想成为的全球金融网络、服务所有用户？以太坊路线图探索过两个答案：`Layer 2` 和区块链`分片`。

`Layer 2` 能在不牺牲三难困境另外两项的前提下提升以太坊的可扩展性。它们是架在主链之上的额外一层，安全性依赖主链，同时让用户享受更低的费用和更快的交易。我们会在 Layer 2 课程里详细介绍。

`分片`本来会把区块链拆成多条并行的链，就像给道路增加车道。以太坊把这个方案放到了一边，选了更简单的一条路：让区块数据对 Layer 2 来说更便宜（2024 年上线），并一步步提升容量，同时不牺牲安全性和去中心化。

![](https://app.banklessacademy.com/images/layer-1-blockchains/so-what-can-be-done-043c43fb.svg)

# 以太坊的未来

以太坊网络在不牺牲三难困境其他方面的前提下，持续提升可扩展性。转向`权益证明`共识的合并（2022 年）把网络能耗降低了 99% 以上，面向 Layer 2 的廉价区块数据则在 2024 年到来。**扩容是一项持续的工作：每一次升级都让以太坊更快、更便宜，同时把安全性和去中心化作为核心信条保留下来**。以太坊基金会有一个很棒的[以太坊路线图](https://ethereum.org/roadmap/)页面。

与此同时，许多 `Layer 2` 协议在以太坊之上构建，帮助满足用户需求，而不需要改动以太坊协议本身。这些 Layer 2 协议依靠 Layer 1 以太坊提供去中心化的安全性，自己则提供可扩展性；Layer 2 的多样性造就了一个去中心化的生态！主要的 `Rollup` 包括 Arbitrum、OP Mainnet 和 Base；Polygon PoS 是一条流行的`侧链`，有自己独立的安全性。

![](https://app.banklessacademy.com/images/layer-1-blockchains/the-future-of-ethereum-1f05c338.svg)

# 这对探索者意味着什么？

用户需要低费用，才能以较低的门槛和较小的试错成本去学习和探索这项技术，刚起步时尤其如此。以太坊区块链还不够理想，但它的价值观让它成为实现「全球金融计算系统」这一梦想的最佳候选之一。探索者可以在不支付高额费用的情况下学着与以太坊交互；使用 Layer 2，探索者既能获得以太坊的安全性和去中心化优势，又能享受更高的可扩展性。

下一课会讲解 `Layer 2` 方案以及如何上手。继续前进吧，探索者！
