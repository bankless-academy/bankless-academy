# 引言

任何区块链的理想状态，都是尽可能做到去中心化、安全和可扩展。要让一条链同时做好这三件事，一直是尚未解决的难题。这个难题有个名字：`区块链三难困境`。

比特币和以太坊都相当去中心化、也足够安全，但扩展性不佳：网络繁忙时，交易费高昂、排队时间长。为了绕开这些限制，探索者可以借助各种技术，大幅降低交易成本、提升交易速度。它们统称为 Layer 2（L2）扩容方案。

`Lightning Network` 是比特币最知名的扩容方案，它依靠`支付通道`技术来扩展支付。以太坊则通过多种 L2 方案来处理交易，缓解三难困境，背后由 2024 年加入主网的廉价临时存储 `Blob` 提供支持（这是当年设想的「分片」的轻量形态）。

![](https://app.banklessacademy.com/images/layer-2-blockchains/introduction-c1f2c88f.svg)

# 支付通道

在比特币区块链上，Lightning Network 依靠双向支付通道，让多方无需在主链上交易就能交换 BTC。

这套架构让两个用户之间开启一条支付通道。每条通道严格只有两方，但支付可以在互联的通道网络中路由，抵达更远的用户。通道开启到关闭之间，双方可以来回转移资金。每位参与者的微型账本条目在双方都签名后更新，这通常要求双方的节点都在线。
任何一方都可以随时把最新版本的微型账本广播到区块链上，从而关闭通道。

支付通道不支持复杂的`智能合约`交互，只支持基础的点对点交易。

![](https://app.banklessacademy.com/images/layer-2-blockchains/payment-channels-31677af9.svg)

# 以太坊的扩容方案

以太坊开发者研究原生扩容方案的时间，几乎和这条网络上线的时间一样长。

多数以太坊社区成员认为，要称得上「以太坊扩容方案」，项目必须在不牺牲`安全性`和`去中心化`的前提下，解决以太坊的`可扩展性`短板。对用户来说，最实际的需求是比以太坊主网更快的交易和更便宜的 `Gas`。为了竞争，有些方案愿意在三难困境上做出比别人更大的取舍。

以太坊的定位由智能合约能力决定，因此扩容方案继承这项能力同样重要。如果用户在 Layer 2 上用不了自己喜欢的 `dApp`，再快再便宜的交易也没有意义。

# 连接 Layer 1 与 Layer 2

正如我们在[区块链基础](https://app.banklessacademy.com/lessons/blockchain-basics)中学到的，区块链是一种叫`账本`的数据库，记录着一份由密码学保护、按时间排序的交易清单。L1 区块链和 L2 扩容方案各自都是完整的区块链，拥有自己的地址和数据。

在不同区块链数据库之间传递信息的基础设施，叫做`跨链桥`。举个例子：把以太坊主网（或任何其他 `L1` 区块链）想象成一座岛，把另一条链或你偏好的扩容方案想象成另一座岛，跨链桥就是连接这两座数字岛屿的高速公路的统称。

这项技术非常复杂，但从终端用户的角度看，整个过程简单到只是选一个目的地。

![](https://app.banklessacademy.com/images/layer-2-blockchains/bridging-layer-1-and-layer-2-c219a748.svg)

# 侧链

`侧链`是一条独立于以太坊运行的区块链，通过`跨链桥`与以太坊主网相连。要迁移代币，你把它们锁在主网的跨链桥合约里，侧链上会铸造出等量的代币。重要的是：这并不会让你的资金获得以太坊的安全性。跨链桥和侧链都依赖侧链自己的验证者。其中任何一方被攻破（比如 2022 年 6.25 亿美元的 Ronin 跨链桥被盗事件），锁定的资金就可能被偷走。

侧链同样受制于三难困境。它们更低的 `Gas` 费和更快的交易，来自一个规模更小但更强大的验证者集合，用一部分去中心化和安全性换来了可扩展性。

Polygon PoS 这类侧链会定期向以太坊发布快照（「检查点」）。这让它们的历史获得某种最终性，也让用户在退出跨链桥时能证明余额，但并不能让侧链上的资金和主网一样安全。

![](https://app.banklessacademy.com/images/layer-2-blockchains/sidechains-464f0191.svg)

# Rollup

使用 Rollup 技术的 Layer 2 协议，在安全级别上与以太坊主网保持更紧密的一致。

和侧链一样，Rollup 让链上交易在以太坊主网之外执行。这些交易随后被「卷起」成一个批次，批次数据以廉价的临时数据包 `Blob` 的形式发布到以太坊，Blob 由 2024 年 3 月的 Dencun 升级引入，也是典型 L2 费用降到几美分甚至更低的主要原因。

为了证明自己足够安全、有资格代表主网处理交易，Rollup 必须提供「令人信服的证据」，说明每个提交批次里的交易都安全有效。这份证据包含在交易的 Rollup 中，并由以太坊主网上的跨链桥合约验证。

目前有两种 Rollup 方法能提供这种证据：`Optimistic Rollup` 和 `ZK Rollup`。我们来仔细看看这两种流程。

![](https://app.banklessacademy.com/images/layer-2-blockchains/rollups-308dc6c9.svg)

# Optimistic Rollup

Optimism、Base、Arbitrum 这些 L2 协议，都采用 `Optimistic Rollup` 作为扩容架构。之所以叫「乐观」，是因为 Rollup 批次里的信息在被证伪之前都默认有效：这是一个乐观的假设。

为了防止有人滥用这种做法，用户申请把资金从 L2 移回主网时，通常要等待数天。在这段时间里，跨链桥的验证者可以发布`欺诈证明`，请求取消这笔提款。这套欺诈证明机制类似银行业的清算流程，只不过是去中心化的。

注意：Across、Relay 这类第三方跨链服务，能让用户在几分钟而不是几天内完成跨链。这些快速桥用自己的资金池先垫付给你，因此你要承担该桥智能合约和资金提供方的风险，比使用 Rollup 自带的桥多了一层信任。

![](https://app.banklessacademy.com/images/layer-2-blockchains/optimistic-rollups-846aad61.svg)

# ZK Rollup

`ZK Rollup` 是一类依靠零知识技术的 Rollup。和 `Optimistic Rollup` 不同，ZK Rollup 确认批次交易是否合法时，不依赖某些用户去寻找欺诈的证据，而是提交一份数学证明，叫做`有效性证明`，让以太坊无需重做计算就能检查整个批次是否正确。

ZK Rollup 最大的优势在于`结算时间`，也叫`交易最终性`。它不需要长达数天的挑战期：只要下一份有效性证明提交，用户通常在几小时内就能在主网动用自己的资金。别被名字误导，这里的零知识技术并不是为了隐私：主流 ZK Rollup 上的交易和以太坊主网一样公开。

已经有一些重要协议在用 ZK Rollup 技术构建以太坊扩容方案，包括 ZKsync、Starknet 和 Linea。这个方向仍处于早期，但未来潜力很大。

![](https://app.banklessacademy.com/images/layer-2-blockchains/zk-rollups-9d65de85.svg)

# 跨链 dApp 兼容性

比较 `Optimistic Rollup` 和 `ZK Rollup` 时，多数用户最关心提款时间。不过这类提款延迟可以用第三方跨链桥解决，所以在挑选扩容方案时，它不该是主要考量。

许多 Optimistic Rollup 做到了「EVM 等效」，也就是这条 L2 原生支持任何能在`以太坊虚拟机`（EVM）上运行的 dApp。EVM 等效意味着此前部署在主网上的智能合约都能直接部署过来，于是 L2 用户也能用上自己喜欢的 dApp。

Polygon PoS 这类侧链同样原生运行 EVM，多数现代 ZK Rollup（比如 ZKsync、Linea、Scroll）也做到了 EVM 等效或非常接近。因此，你喜欢的以太坊 dApp 在大部分 L2 生态里都能用。

![](https://app.banklessacademy.com/images/layer-2-blockchains/cross-chain-dapp-compatibility-8a372647.svg)

# 课程回顾

比特币、以太坊这样的 L1 区块链，目前都受制于`区块链三难困境`。比特币网络上的`支付通道`，以及以太坊上的侧链和 Rollup，帮助这些网络扩容、缓解三难困境。

`跨链桥`把 L1 区块链与`侧链`和 `Rollup` 连接起来，而跨链桥合约的运作方式，决定了所连接网络的性质。

侧链上的资金并不继承以太坊的`安全性`：跨链代币被锁在主网的合约里，但它们是否安全，取决于侧链自己的验证者和跨链桥合约。这类链拥有规模小但强大的验证者集合，因而能提升交易速度、降低 Gas 费，代价是去中心化和安全性。

Rollup 和侧链一样也自行验证和处理交易，但它们的跨链桥合约要求先提供交易有效的「令人信服的证据」，数据才被认可。这让它们的`安全性`和`去中心化`程度与以太坊的价值观保持一致。提供这种「证据」有两种方法：Optimistic Rollup 和 ZK Rollup。`Optimistic Rollup` 在主网结算交易批次前会留出数天延迟，期间由跨链桥验证者发现并举报欺诈。`ZK Rollup` 则借助`零知识`技术，为交易的合法性提供数学保证。

目前，Optimistic Rollup 和现代 ZK Rollup 都与以太坊主网有很高的智能合约兼容度，主网上的 dApp 可以轻松部署到它们的网络上。许多人相信，凭借快速最终性和强有力的有效性保证，ZK Rollup 会成为未来的扩容方案。
