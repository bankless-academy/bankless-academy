# 以太坊基础

欢迎你，探索者，来到 Bankless Academy 最重要的课程之一。

今天我们要认识以太坊：互联网的下一个时代。它是一个革命性的平台，支撑起一个由全新互联网`应用`和数字货币组成的世界。

理解以太坊有个简单的办法：把它想成 Google 或 Apple 的`应用商店`，但有几个关键区别：

- 💸 它用的是`加密货币`，而不是`法定货币`（美元、欧元或人民币）。
- 📡 它是直接加在你浏览器上的一层，为网站解锁全新功能。
- ⚖️ 商店的规则由用户和应用开发者共同商定，没有哪家中心化公司说了算。

要理解为什么全球有数百万人在使用以太坊，我们得先看看它的核心使命……

![](https://app.banklessacademy.com/images/ethereum-basics/ethereum-basics-b2e09ce5.png)

# 全球广场

过去四十年里，互联网已经成为全世界的公共广场。

在这里，素不相识的人彼此连接，交流想法、商品和服务，甚至一起点燃全球性的运动。这是人类连接、创造与创新最强大的交汇点。

**但它有一个大问题……**

![](https://app.banklessacademy.com/images/ethereum-basics/a-global-town-square-fcb47024.svg)

# 中心化服务

**互联网依赖着一小群公司，而它们并不总是把我们的利益放在心上。**

`中心化服务`对互联网的控制力前所未有，几乎你在网上做的每一件事，它们都充当`中介`。

想想大银行如何管理你的消费，Facebook 和 Instagram 如何连接你的社交往来，Apple 或 Google 如何决定你手机上能装哪些应用。凭借各自的规则、费用和商业动机，它们对你的数字往来有着惊人的影响力。

![](https://app.banklessacademy.com/images/ethereum-basics/centralized-services-adf5be05.svg)

# 不对等的交易

我们称它们为`中心化服务`，因为所有权力都集中在一处。这常常像被困在一位国王的统治下，他很清楚怎样从你身上拿到想要的东西。你可能会对这些交易的真相感到意外……

💸 银行向你收取费用，并拿你的钱去投资，为自己牟利。

💳 Visa、Mastercard 这样的支付网络，把你的消费数据卖给广告商。

📞 Instagram 这样的社交平台，可以查看你的私人对话。

🪓 YouTube 这样的内容平台，可以随意抹掉创作者的整个事业，且不给公正的申诉机会。

这些不透明的规则和费用往往藏在「服务条款」里，而且往往越改越苛刻。在这里看看你常用服务的协议吧：[https://tosdr.org/](https://tosdr.org/) 👀

# 开放的互联网

😤 **受够了那些不尊重你需求的平台？**

---

这就是我们已经习以为常的`价值榨取型`互联网。

这些服务被称为「围墙花园」，因为它们限制很多，想离开也很难。寻找更好的替代品既费时又费钱，于是我们常常觉得，不如忍下高额费用、不透明和不对等的交易。

我们需要一个更公平、更可靠的互联网，不再受制于中介和它们的围墙花园。我们需要一个由用户掌握权力的网络空间，正如互联网最初被设计的那样。

![](https://app.banklessacademy.com/images/ethereum-basics/an-open-internet-31819e5b.svg)

# 点对点交易

解决办法要从改变互联网的连接方式开始。

在传统互联网服务里，信息或资金从一个`对等方`出发，要先经过一个`中介`关卡，才能抵达目的地。理论上，中介在交易完成前可以为所欲为。

**对等方 → 中介 → 对等方**

但还有第二种模式，叫`点对点`网络。它用自动、透明的计算机代码取代中介服务。

**对等方 → 自动化 → 对等方**

这就像把中介换成自助服务终端。服务变得更可预测，费用下降，用户重新拿回控制权。

我们接下来会看到，点对点的互联网会改变一切。

![](https://app.banklessacademy.com/images/ethereum-basics/peer-to-peer-trades-f043c3c0.svg)

# 以太坊：开放的互联网

⚖️ **如果同一套规则对所有人都适用，互联网是不是会更好？**

把以太坊想成一座数字城市，城里的一切（从生意到公共服务）都由自助、透明的系统运行。这里没有中介，任何人都可以查看每个系统是怎么运作的。

城里的交易都记录在一份公开记录上，叫`以太坊区块链`。区块链追踪并保存城中的数字财产，也省掉了另一个经典中介：银行！

每笔交易都要付一小笔费用。其中大部分会被销毁，城市越繁忙，它的货币`以太币`就可能越稀缺。剩下的一点小费，奖励给处理你这笔交易的计算机。

城市的规则不由任何公司制定：改动由开发者、研究者和用户公开商定。透明的代码取代了国王，没有人凌驾于规则之上。

![](https://app.banklessacademy.com/images/ethereum-basics/ethereum-the-open-internet-ab794154.svg)

# 去中心化经济

要访问以太坊，你会用电脑或手机上的浏览器。只需要一个账户，你就能登录整个新互联网：这个统一登录凭证叫`加密钱包`。有了这个通用账户，切换服务、逃离「围墙花园」都变得更容易。

开启以太坊应用层后，你就能访问一类新网站，叫做 `dApp`。它们就是前面说的自助系统。dApp 提供各种数字商品和服务，例如：

- 🤝 收发或买卖货币、股票等数字资产，但**费用低、全天候可用**。
- 📻 与你喜欢的创作者连接，还能**解锁独特的福利和机会**，同时确保你的钱直接到达创作者手中。
- 👪 社交媒体，但如果你不喜欢这个平台，可以**轻松把社交圈搬到新平台**。
- 🗳️ 给你支持的项目捐款，哪怕只捐 1 美元，也能拿到**高额配捐，影响力更大**。
- ⚙️ 把你电脑的算力出租，赚取**被动收入**。

以太坊去掉了中介和银行，也不用为每个服务单独注册账户，让它的经济变得`去中心化`（这就是 dApp 里的那个「d」）。dApp 之间比拼的是质量，而不是含糊的商业手段和控制力，所以会越做越好。

# 使用一个 dApp

使用 `dApp` 和使用普通应用、互联网服务差不多。

我们来模拟用一个 dApp 在线兑换`加密货币`。这次模拟里，我们把 USDC 换成以太坊的原生货币 `ETH`。USDC 是 Circle 公司发行的`链上`美元，也就是说 Circle 可以冻结它。

1. 把你的`加密钱包`连接到 dApp 的网站。
2. 确认你允许这个 dApp 与你的以太坊钱包交互。
3. 点击「Maximum」，把全部 USDC 换成 ETH。
4. 发起兑换。
5. 在钱包里核对这笔交易的条件，然后签名。
6. 很好！以太坊已经处理了你的加密货币兑换！

把钱包接入 dApp 并兑换加密货币，就是这么简单。现在你可以把它发给朋友、用来消费，或者试试其他金融服务类 dApp。

---

⚡ 用加密货币，你几秒钟就能把钱转到世界任何角落。如今大部分日常活动都发生在 `Layer 2` 网络上，那是建在以太坊之上、更快更便宜的通道，一笔转账可能只要一美分。相比之下，通过银行汇款要付 3-4% 的手续费，还要等 1-5 天。

在以太坊上，你就是自己的银行，而且感觉确实如此！

# 它是如何运作的

我们把前面的内容串起来，快速看看以太坊是怎么做到这一切的。

作为一个`点对点`网络，以太坊由分布在全球的数千台计算机组成，这些计算机叫`节点`，任何人都可以运行。有些运营者锁定（`质押`）自己的以太币，让节点成为`验证者节点`：它们的软件处理交易，并复核别人的结果以防欺诈，作为回报赚取`以太币`奖励。大多数人是通过[质押服务](https://app.banklessacademy.com/lessons/staking-on-ethereum)参与，而不是自己运行计算机。

![](https://app.banklessacademy.com/images/ethereum-basics/how-it-works-08c71cad.svg)

# 它是如何运作的（第二部分）

你刚才提交的那笔交易，就是由这些以太坊网络的`验证者节点`处理的。

1. 你的 ETH 交易被提交到以太坊网络。
2. 一个`验证者`检查你的交易有没有错误，其他验证者再复核结果。
3. 你的交易被写入网络的公开账本，也就是`以太坊区块链`。
4. 我们在账户里收到了你转来的 ETH。

你可能会想，这些验证者为什么不干脆卷走你的钱？简短的答案是：以太坊让这几乎不可能。接下来的「区块链基础」一课会帮你理解得更透彻。

# 常见问题

<details>
  <summary>以太坊是怎么诞生的？</summary>

以太坊于 2015 年上线，早期开发由以太坊基金会协调，今天它仍然扮演这个角色。升级方案由开发者、研究者和更广泛的社区通过公开流程商定，既没有公司拍板，也没有代币投票。这份开放性支撑着网络创立时的愿景：一个开放的互联网。

</details>
<details>
  <summary>以太坊安全吗？</summary>

你在以太坊上的数字财产无法被直接偷走。不过，骗子可能诱骗你把资产的访问权交出去。我们的「Web3 安全」一课会教你保护自己的基础知识，避开那些会让你损失金钱的低级错误。

</details>
<details>
  <summary>以太坊的使用范围广吗？</summary>

很广。2024 年，美国监管机构[批准了现货 ETH 投资基金（ETF）](https://www.forbes.com/sites/lawrencewintermeyer/2024/07/25/ethereum-on-the-brink-of-market-transformation-as-etfs-get-green-light/)，让人们可以通过传统股市投资以太坊。[Sony](https://www.bankless.com/sony-introduces-soneium-its-ethereum-l2-network) 和 [Visa](https://caribbean.visa.com/about-visa/newsroom/press-releases/visa-network-to-settle-transactions-in-usd-coin-usdc.html) 这样的企业甚至在它上面开发产品。

</details>
<details>
  <summary>以太坊会被用于犯罪活动吗？</summary>

[Chainalysis 的行业研究](https://www.chainalysis.com/blog/2026-crypto-crime-report-introduction/)一直估计，与犯罪活动相关的加密货币交易量不到 1%。这远低于[全球 GDP 的 2-5%](https://www.forbes.com/sites/haileylennon/2021/01/19/the-false-narrative-of-bitcoins-role-in-illicit-activity/)这一涉嫌犯罪活动的估计比例。以太坊高度透明，也让调查人员更容易追踪并起诉在`链上`作案的罪犯。

</details>
<details>
  <summary>以太坊节能吗？</summary>

随着以太坊的日常使用量增长，社区发现它的环境影响也在变大。一次名为「合并」（The Merge）的重大网络升级[把以太坊的能耗降低了 99.9%](https://www.newscientist.com/article/2369304-cryptocurrency-ethereum-has-slashed-its-energy-use-by-99-99-per-cent/)。这一成果展示了以太坊适应用户需求的能力！

</details>
<details>
  <summary>我该怎么投资以太坊？</summary>

想投资以太坊，你需要持有网络的原生加密货币 `ETH`。ETH 可以通过你的`加密钱包`购买，下一课我们就会帮你创建自己的钱包。你也可以在 Coinbase 或 Binance 这类`中心化交易所`买 ETH，但要先转到钱包里，才能在以太坊上使用它。

</details>
