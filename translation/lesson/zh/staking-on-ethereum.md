# 在以太坊上质押

欢迎你，探索者，来到新的一课！

今天我们来看看「质押」：一种积累数字财富的简单方式。

`质押`和比特币网络上的`挖矿`很相似：两者都是让参与者处理区块链上的交易、换取奖励的机制，也都让我们的网络保持`去中心化`。

不过挖矿和质押有个重要区别。在以太坊上质押，不需要用强大的电脑去和别人竞争。只要把以太币（ETH）锁进网络的`智能合约`，就能让以太坊运转下去，并获得奖励。

![](https://app.banklessacademy.com/images/staking-on-ethereum/staking-on-ethereum-50472cf7.png)

# 以太坊需要你！

把`质押`想象成一种「互联网债券」。

就像买政府债券支持国家能带来财务回报一样，支持以太坊也有奖励！更棒的是，和政府债券一样，质押也是一种用财务行动表达价值观、支持你想要的世界的方式。

当你质押以太币时，它会被分配给一个正在处理以太坊交易的`验证者节点`。质押的以太币越多，以太坊能拥有的节点就越多。节点越多，以太坊就越`去中心化`、越安全。

作为一名`质押者`，你成为了**以太坊的守护者！**

现在，我们来深入了解质押的运作机制，找到一个轻松、低成本的方式，今天就开启你的质押之旅。

带上装备，出发吧！

![](https://app.banklessacademy.com/images/staking-on-ethereum/ethereum-wants-you-fd40b9e5.png)

# 区块链安全

`验证者节点`是以太坊经济安全、可信的关键。它们保护区块链免受`欺诈`。

区块链世界里的欺诈，是指用户篡改余额或凭空造出不存在的加密资产。以太坊遏制它的办法，是确保每一笔交易都有效，且没有任何参与者能凌驾于他人之上。这种公平叫做`可信中立`，至关重要。为什么？没人愿意待在一个充满欺骗和不信任的经济体里，它最终会崩塌。

在一条健康的区块链上，验证者节点有共同的目标：**在全网范围内，就区块链的状态达成去中心化的一致。** 节点会扫描交易，对照区块链的历史核对，并对其有效性投票。通过节点`共识`、被认定有效的交易，才会被写入区块链。

![](https://app.banklessacademy.com/images/staking-on-ethereum/blockchain-security-7f2149fe.svg)

# 权益证明

想运行`验证者节点`的用户必须锁定至少 32 ETH，这是一笔不小的钱。（自 2025 年起，单个验证者也可以持有更高的余额，质押者随时可以通过排队退出。）作为在网络中投入大额「权益」的回报，`节点运营者`可以在以太坊上提议和审核交易区块，并赚取奖励。你可以把区块理解成提交给网络的一组交易。

网络的`共识机制`会随机选出一个验证者节点来提议下一个区块，它的决定会由其他节点复核，以确保诚实。当一个节点成功提议一个区块，它的`质押`就会增长。

![](https://app.banklessacademy.com/images/staking-on-ethereum/proof-of-stake-49c358ed.svg)

# 罚没

当一个节点被证实作弊，比如签署两个相互冲突的区块，它的质押就会`被罚没`：损失一部分以太币。反应慢或者掉线不算`罚没`，那只会带来一点小惩罚。这样一来，质押的以太币就成了保证金，激励节点保持诚实、让以太坊平稳运行。

攻击者若想在以太坊上让欺诈通过，必须控制多数验证者节点，也就是多数质押的以太币。好在只要普通用户参与质押，这种情况就不会发生。网络所有权的`去中心化`，把决策权分散开来。

![](https://app.banklessacademy.com/images/staking-on-ethereum/slashing-ccabe137.svg)

# 验证交易

我们来一步步看看，节点如何用`权益证明`共识达成一致：

1. **质押：** `节点运营者`在网络上锁定 32 ETH，开始运行`验证者节点`。
2. **区块构建：** 用户提交交易，由`区块构建者`把它们整理成`区块`。
3. **提议者选择：** 算法选出一个验证者节点，来提议下一个要加入区块链的区块。
4. **区块提议：** `区块提议者`审核候选区块并选出一个，若有效就给予`证明`。
5. **交叉验证：** 其他验证者复核该区块，若有效同样给予证明。无效区块会被直接忽略，永远不会进入链上。
6. **区块写入：** 有效的区块被加入以太坊区块链。
7. **奖励：** 区块提议者获得`区块奖励`和交易小费。其他验证者也会获得奖励。

# 以太经济学

质押者把以太币提供给验证者节点，就能分到它的一部分奖励。

节点获得的奖励取决于多种生态因素，也会变化。简单说，奖励来自交易费的一部分，加上写入新区块的少量新发行以太币。

年化收益会随时间变化，历史上大致是质押以太币的百分之几。具体数额由两个关键因素决定：

- 📈 **网络活跃度：** 一般来说，网络流量低，奖励就低；流量高，奖励就高。
- 👥 **验证者节点数量：** 参与者越多，奖励分得越细。

收益也取决于你具体用哪种方式质押以太币。我们来看看有哪些选择。

![](https://app.banklessacademy.com/images/staking-on-ethereum/ethernomics-33407ddc.svg)

# 质押的方式

运行`验证者节点`通常需要锁定 32 ETH，但新的质押方式让守护以太坊变得人人可及。

所以，保护以太坊有三种方式：

- 📡 **单独质押：** 自己运行一个验证者节点。
- ⛲ **质押池：** 加入一群质押者，一起运行节点。
- 🏦 **中心化交易所质押：** 加入「加密银行」的节点。

每种方式在设置时需要的技术知识各不相同，也各有各的风险。

如果你愿意自己保管`私钥`，但没有 32 ETH，那可以考虑和别人一起加入质押池。

# 网络中心化

**任何让大量节点集中到同一个实体手里的质押方式，都会让以太坊走向中心化。**

把以太坊想象成一张由`验证者节点`连成的网。当节点集中在一个或少数几个实体手里，整张网就会失衡、不再安全。为了避免这种情况，我们需要大量彼此独立的连接点。

单一实体掌控足够多的节点是件坏事。这会迫使交易区块从网中被中心化的那一段通过。这个中心化实体可能开始批准欺诈区块，甚至拒绝有效的区块，从而摧毁以太坊的`可信中立`。

作为守护者，我们必须关注那些让这张网保持均衡和`去中心化`的质押方式。

作为新手，自己运行验证者节点会遇到不少门槛。我们不如来看看一个对新手友好的去中心化质押选择：`质押池`。

![](https://app.banklessacademy.com/images/staking-on-ethereum/network-centralization-0622ba07.svg)

# 质押池

`质押池`最大的好处，是它完全由`智能合约`运行。你不必和其他质押者见面，也不必信任他们。但你确实需要信任那份智能合约。

质押池由`质押服务商`组织，这些数字平台把全世界的质押者连接起来！在质押池里，一位`节点运营者`拿出 32 ETH 中的一部分并运行节点，其余以太币由其他参与者提供。节点运营者因为提供这项服务而获得额外收益。

其余质押参与者会拿到「流动性质押代币」（LST），代表他们在池中的成员份额。这些`代币`代表池中质押以太币的一部分，持有者按所代表的份额分得奖励，并可以随时用它赎回自己的质押。

只要持有一枚 LST（比如 Rocket Pool 的 rETH），你就拥有一个质押池的份额。没错，你的以太币正在让以太坊更去中心化，同时赚取质押奖励！

![](https://app.banklessacademy.com/images/staking-on-ethereum/staking-pools-46c96251.svg)

# 流动性质押代币

`LST` 最大的好处在于：即使你的以太币已经质押并在赚取收益，它依然保持`流动性强`的形态。

这里的「流动」是指它仍然可以在整个生态中流转。想象一下你手里握着质押池的份额……而它还能当钱用！LST 可以拿去兑换、当作贷款的抵押品，甚至存进`再质押`平台，那是一种可选策略，用额外的风险换取额外的收益。

LST 很棒，因为它打开了通往质押以太币的大门。质押池往往对入池金额设有下限（大约 0.01 ETH）。但通过 LST，你可以在自己喜欢的`去中心化交易所`上买到更小份额的质押以太币。

# 又是网络中心化！

质押池和 LST 也有和各种质押方式一样的问题：**它们的中心化与去中心化程度各不相同。**

像 Rocket Pool 这样的`质押服务商`已经做到，让任何地方的任何人都能成为质押池的`节点运营者`。这帮助新的节点运营者攒够 32 ETH 的质押，也让以太坊更去中心化。但也有服务商只允许一小圈熟人来运行节点，这就带来了质押以太币中心化的风险。

如果某个实体控制了全部质押以太币的 33% 以上，就可能给网络制造麻烦。到了 50%，它会严重威胁以太坊的`可信中立`。

一些大型质押服务商已经接近过 33% 这条线。把质押分散到多个服务商，才能让网络保持安全。

要守护以太坊，我们需要做功课。即使用`质押池`，我们也要做出支持去中心化的选择。
