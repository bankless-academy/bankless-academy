# DeFi 的定义

DeFi 是 decentralized finance（`去中心化`金融）的缩写，指运行在公共`区块链`网络上的一整套金融产品、协议和应用。

DeFi 是传统金融服务之外一个成熟、开放的选择，提供了一系列工具，让你的加密资产动起来。它带来的机会不止于在中心化交易所买币，还让任何人都能建立去中心化的 Bankless 生活方式。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-defined-759c5922.svg)

# 为什么选择 DeFi？

只要有网络连接，DeFi 就能让任何人用上复杂的金融工具：投资、交易、借贷和质押。

DeFi 以透明、开放的方式提供这些工具。任何人都可以查看代码，验证合约确实在做它宣称的事，而银行处理你的钱时都是关起门来的。

而且中间没有任何机构决定谁能参与：没人能把你拒之门外，没人能冻结或关闭你的账户。

# 赚取收益

许多 `DeFi` 协议让你把加密资产用起来，赚取利息和其他奖励。你能用上通常要靠银行或金融服务公司才能提供的金融产品，不必经历传统金融那套文书、审批和繁琐流程。

DeFi 不是免费的：每笔交易都要付一小笔网络费用，很多协议也会收费。但这些成本通常更低、也完全透明，没有银行的管理开销，也没有机构能卡住你的使用权或收益。这正是 DeFi 受欢迎的原因。

![](https://app.banklessacademy.com/images/intro-to-defi/earning-yield-bc952747.svg)

# DeFi 能做什么

`DeFi` 交易是`无需许可`的。这指的是任何人都能使用的公共`区块链`，可以在上面买入、卖出或交易资产。没有第三方控制或监管这些活动。这些交易由去中心化应用完成，也就是 dApp。

`dApp` 和 DeFi 平台全天候运转，遍布全球。很多平台建立在`稳定币`之上，这类代币的设计目标是保持稳定的美元价值（见我们的[读懂稳定币](https://app.banklessacademy.com/lessons/understanding-stablecoins)课程）。下面我们会介绍 DeFi 中最常见的四种活动：投资、交易、借贷和质押。

![](https://app.banklessacademy.com/images/intro-to-defi/what-you-can-do-with-defi-e1e865b5.svg)

# 投资

最常见的 `DeFi` 交易，是买入一些加密货币，期待它将来更值钱。这就是投资。

HODL 是长期持有加密资产的说法。至于它的来历，有人说是 HOLD 的拼写错误，也有人说它代表 **H**old **O**n for **D**ear **L**ife（拼命拿住）。

DeFi 还能让你在新币和新代币登陆中心化交易所（CEX）之前，就提前接触到它们。

![](https://app.banklessacademy.com/images/intro-to-defi/investing-7c8b44ed.svg)

# 交易

去中心化交易所（DEX）会显示不同加密代币和币种之间的当前汇率，它是一个数字市场，把买家和卖家聚到一起，方便他们把一种货币换成另一种。

在 DEX 上交易的双方不需要认识或信任彼此。事实上，看起来你像是在和 DEX 交易。但多数情况下，DEX 会创建`流动性池`，以`无需许可`的方式促成两个交易者`钱包`之间的兑换。

![](https://app.banklessacademy.com/images/intro-to-defi/trading-67935721.svg)

# 所以呢？

无论净资产多少，任何人都能参与交易和市场。任何人都能通过链上协议建仓或平仓。

# 借出与借入

DeFi 的借贷不需要银行或中介机构。放贷发生在`点对点`层面：`dApp` 直接把出借人和借款人连起来。出借人赚取利息，借款人偿还本金加利息。

要借款，你得先存入价值高于贷款的加密资产作为`抵押品`。如果抵押品价值跌得太多，它会被自动卖出来偿还贷款。这叫`清算`，也是 DeFi 贷款不做信用审查却能保持安全的方式。

![](https://app.banklessacademy.com/images/intro-to-defi/lending-borrowing-b7d58dfa.svg)

# 质押

`质押`常和借贷放在一起讲，但两者不同：质押没有借款人。你锁定自己的`以太币`来帮助保护以太坊网络，网络则以奖励回报你。

质押的资金可能会被锁定一段时间，行为不端的`验证者`会失去一部分质押，所以诚实才划算。中心化交易所也提供质押，但 DeFi 给你更多选择，同时让你保持对资产的控制权。想了解更多，请看我们的[在以太坊上质押](https://app.banklessacademy.com/lessons/staking-on-ethereum)课程。

# DeFi 的缺点

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-da1fdb68.svg)

**黑客**

哪里有钱和技术，哪里就有人想办法攻破系统。DeFi 协议和它们的用户经常成为目标，所以安全习惯很重要。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-d533aeef.svg)

**风险**

DeFi 运行在代码上，也就是`智能合约`。代码里的错误或漏洞可能被利用来掏空资金。市场也带来风险：价格下跌时贷款会被清算，`稳定币`也可能失去稳定的价值。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-0070f0e1.svg)

**无处申诉**

这里没有客服电话，出了问题也没有公司或政府机构可以申诉。丢失或被盗的资金通常无法撤销或赔付。
