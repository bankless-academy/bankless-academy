# 什么是去中心化交易所？

去中心化交易所（DEX）是链上市场，让探索者在保持钱包资金自我托管的同时，安全地与其他用户交换加密货币。这些点对点买卖通过公开可用的智能合约完成，把用户连接到共用的大型代币金库。这些金库叫做`流动性池`。几乎每条区块链上都有 DEX，以太坊 Layer 1 和 Layer 2 上也都有。

兑换代币是使用 `DeFi` 的必备一环。在 DeFi 里，你能找到比其他任何类型的交易所都更丰富的代币种类和用途。有些用户买代币是为了使用链上产品和服务，有些人把代币当作投资。还有些代币赋予持有者投票权，用来决定项目方向，就像持有传统公司的股份一样！无论出于什么动机，在 DeFi 中你都会经常光顾 DEX。

我们来看看它们如何运作，以及怎样最好地为你服务。

![](https://app.banklessacademy.com/images/decentralized-exchanges/what-is-a-decentralized-exchange-7eed6afb.svg)

# 中心化交易所与去中心化交易所

我们来讲讲中心化交易所（如 Coinbase、Binance、Kraken）和去中心化交易所（如 Uniswap、PancakeSwap）在技术上的区别。

中心化交易所（`CEX`）让用户买卖和投资加密货币，而不必真正接触区块链生态本身。由于你的账户注册在 CEX 上，你的私钥和资金由它们保管：你要承担它们的管理方式、规则和商业模式带来的风险。

去中心化交易所（`DEX`）让用户完全在自我托管的状态下买卖加密货币，这正是区块链最初的设计目的。点对点模式让你既是消费者也是提供者，接触到过去只有金融阶层才有的机会。区块链系统既透明又抗审查：没有人能冻结你的访问权，也没有人能撤销你的买卖。黑客攻击的风险依然存在，本课后面会讲到。

![](https://app.banklessacademy.com/images/decentralized-exchanges/centralized-and-decentralized-exchanges-f6f6324c.svg)

# 去中心化应用

DEX 是一种 `dApp`，也就是运行在区块链上的去中心化应用。一个互联网应用要算得上「去中心化」，必须无差别地允许任何人使用，不需要第三方参与就能处理用户的交互，而且代码公开透明。

dApp 的服务由智能合约提供。智能合约是一段代码，接收用户的链上操作，返回可预期的链上结果。以太坊基金会把智能合约比作自动售货机：用户输入想要商品对应的编号，投入相应的钱，就能得到预期的输出（零食），不需要另一个人来促成这笔交易。

DEX 智能合约可以处理多种指令，比如代币兑换、投票，或者增加和移除`流动性`。

![](https://app.banklessacademy.com/images/decentralized-exchanges/decentralized-applications-99447b26.svg)

# 去中心化应用（续）

DEX 遵循与自动售货机相同的逻辑：接收用户输入的代币，输出想要的代币。其他 dApp 的例子还包括：

🎟️ **投票 dApp**：把用户的投票分配给指定对象。

📦 **跨链桥 dApp**：把用户的加密货币从一条区块链网络转移到另一条。

🤝 **借贷 dApp**：向符合特定条件的用户发放贷款。

智能合约是以太坊上的账户：它们有地址和余额，在收到转账和指令时执行自动化操作。DEX 就是一个被编程过的以太坊账户，带有若干可用功能。

`dApp` 通常会用一个网站作为可视界面，帮助用户与底层智能合约交互。如果网站宕机了，有经验的人依然可以直接访问智能合约！

# 自动做市商

在传统市场和 `CEX` 上，托管方使用`订单簿`：一个装满买单和卖单的数据库。CEX 把你的报价和另一个人的报价撮合起来。你通常要按固定或阶梯比例支付佣金，而且你无从判断这套不公开的撮合方式是否给了你最好的价格。

大多数 `DEX` 使用「自动做市商」（`AMM`）技术，这是代币兑换最常见的设计：用公开算法为你的买卖定价。一些较新的 DEX 改用订单簿或基于意图的系统。由于 AMM 算法是开源的，任何人都能理解、复制和改进它，这带来了良性竞争和持续创新。

AMM 把用户的买卖路由到`流动性池`，而不是直接撮合买家和卖家的报价。这些共用的代币金库根据用户的交互积累和释放代币，每一步都在公开的区块链上可见。

![](https://app.banklessacademy.com/images/decentralized-exchanges/automated-market-makers-78ad7439.svg)

# 代币兑换

区块链上的加密货币买卖叫做`代币兑换`。这类智能合约交互通过 AMM `流动性池`把一种加密货币换成另一种。DEX 智能合约会构建一条`交易路径`，也就是穿过合适流动性池的通道，把你输入的代币换成你想要的代币。由于每个池通常只装两种代币，而且不是每个`代币对`都有池，一次兑换可能要经过好几个池才能完成。

要让智能合约动用我们钱包里的资金，我们需要授予它提取一定额度（或无限额度）的权限。这些`代币授权`让受信任的合约不需要我们的私钥就能执行交易。授权要花 Gas，所以权限会一直开着以备后用，这也是「用一个钱包买卖、用另一个钱包持有」的原因之一。我们在[管理代币授权](https://app.banklessacademy.com/lessons/managing-token-allowances)这一课里讲了如何监控和撤销授权！

![](https://app.banklessacademy.com/images/decentralized-exchanges/token-swaps-41ceb8e1.svg)

# 代币兑换（续）

我们来看一个兑换的例子，理解授权和交换的流程。这个例子是在 Optimism 网络的大型 DEX Velodrome 上，把 USDC 换成 OP。这笔买卖经常要经过两个池，因为 USDC/OP `流动性池`的成本效率没那么高：

1. 首先，你授予相应的 Velodrome 智能合约从你钱包提取 USDC 的权限。
2. 你向 Velodrome 提交兑换交易请求。
3. 交易被接受：Velodrome 从你的钱包提取指定数量的 USDC，存入 USDC/ETH 流动性池。等值的 ETH 离开第一个流动性池，转入 ETH/OP 流动性池。最后，OP 从第二个流动性池转到你的钱包地址。

兑换交易完成。你的 USDC 代币经由 ETH 换成了 OP！

# 什么是流动性？

在加密领域，流动性指的是一个市场以公平价格促成数字资产买入和卖出的能力。流动性高时价格更稳定，流动性低时价格更波动。用户普遍被更公平的价格吸引，所以 `DEX` 都力求让自己所有的流动性池保持高流动性。

高流动性意味着流动性池里有大量代币，通常是用户进出的两种代币各占约 50/50 的价值。比如一个 USDC/ETH 池，承担该平台上这个`代币对`的所有买卖。
池里代币越多，通过池子买卖的用户对 50/50 资产平衡的影响就越小，价格也就越稳定。任何一笔买卖打破这个平衡的幅度，叫做`价格影响`。

作为探索者，你希望自己买卖的价格影响越小越好，这样才能拿到最好的价格！也就是说，你需要高而均衡的流动性。

![](https://app.banklessacademy.com/images/decentralized-exchanges/what-is-liquidity-a88af170.svg)

# 流动性提供者

争取高`流动性`对 DEX 的成败至关重要，但加密生态里的流动性总量有限，所以每家 DEX 都在竞争尽可能多地吸引流动性。那么这些流动性从哪来？

在去中心化的生态中，DeFi 公民有动力向某个池提供流动性，以抬高平台的 TVL（总锁仓价值）。用户通过池子买卖时产生的费用，会按提供的流动性数量分给 LP（流动性提供者）。你没听错：把代币借给 DEX 流动性池，就能产生被动收入。

成为 `LP` 需要考虑的因素很多，我们会在后续内容里讲。现在你只需要知道，DEX 流动性池上标出的高 APR（年化收益率）并没有保证，也可能出现亏损。

# 平台费用

CEX 和 DEX 都会为自己的服务收费，与区块链交互也不是免费的。选择平台时，要考虑以下五种常见成本。

🏷️ **平台费用**：CEX 自行设定买卖佣金，DEX 的池费用则因池而异（通常不到百分之一）。关键区别在于：DEX 的费用在链上公开，任何人都能查。

🌐 **网络费用**：区块链会在 dApp 交易之外收取 Gas 费。你可以在网络空闲时段操作来降低这部分成本。Etherscan.io 提供以太坊主网的实时 Gas 估算工具：[Etherscan.io](https://etherscan.io/gastracker)。Layer 2 上的费用便宜得多，可以在 [growthepie](https://www.growthepie.com/) 比较各个网络。

📦 **跨链桥费用**：CEX 和区块链跨链桥都会为跨网络转移加密货币收费。CEX 的收费请查看它们站内的说明；跨链桥 dApp 会在你确认转账前显示费用估算。

💹 **汇率**：在 CEX 或 DEX 上直接用法币购买加密货币时，要小心那些不反映市场价的汇率。

🧊 **滑点**：价格变化很快，所以 DEX 会为兑换留出波动空间，这叫做`滑点`（可自定义，通常为 0.5-2%）。一笔买卖你最多可能损失这个比例的价值，但设得太低又可能导致买卖被拒绝。

买卖前一定要做好自己的研究，弄清楚一个平台的成本和取舍。

# DEX 的优势

这一课讲了很多理论，但你可能还在想 DEX 是否适合自己。一般来说，如果符合以下情况，你大概会从去中心化交易所中获益：

- 🔑 你想保有对数字资产的托管权。
- 🔒 你想把资产放在区块链上，避开 CEX 倒闭。
- ⌛ 你想全天候进入加密货币市场。
- 👛 你想接触更多种类的加密货币。
- 🤑 你对提供流动性感兴趣。
- 🛂 你不想在每个用到的平台上都注册并完成 `KYC`。
- ⚔️ 你愿意承担探索去中心化金融带来的额外风险和回报。

话虽如此，几乎每个 DeFi 用户都有中心化交易所的账户。因为 CEX 有便捷的法币出入金通道，你可以轻松把钱从银行账户搬到区块链上，反过来也一样。[Ryan Sean Adams](https://twitter.com/RyanSAdams) 把这比作用公共厕所：_「进去，办完事，出来。」_

这样很好，因为这意味着你可以从 CEX 账户起步，随着你对链上操作越来越熟练，慢慢转向 DeFi。

# DEX 的风险

使用 DEX 也有风险。以下是影响最大的几种：

🐞 **智能合约风险**：审计能降低智能合约出 bug 的概率，但无法消除。2025 年，一家经过多家机构审计的大型 DEX 因为一个隐蔽的代码漏洞损失了 1.28 亿美元。最坏的情况下，你可能损失相当于买卖金额的资金。请优先选择受信任、经过充分审计的智能合约。

💰 **自我托管风险**：私钥完全由你负责，意味着你可能因为盗窃、骗局或助记词丢失而失去整个钱包。所以要用多钱包策略来分散风险，并且始终把助记词备份保存在安全的现实场所。

🥪 **三明治攻击**：把兑换滑点设得很高，会让抢跑者更容易对你发动`三明治攻击`。在三明治攻击中，一笔买卖你最多可能损失滑点设定的比例。我们会在后续内容中讲如何防范这类攻击。

综合这些优势和风险，如果符合以下情况，CEX 可能更适合你：

- 🎓 你还处在加密之旅的早期，正在弄懂其中的风险和回报。
- ⚖️ 你的买卖频率和金额都很小，链上手续费不划算。
- 🏰 比起自己承担责任，你更愿意让交易所帮你看管资金。

有些用户采取混合策略来降低整体风险：用 CEX 买卖加密货币，再把资产存放在区块链上。

# 选择一家 DEX

DeFi 里有很多去中心化交易所，质量参差不齐。决定用哪一家时，可以考虑这五个关键因素：

🥇 **可信度**：这家机构在可靠性、质量和存续时间上口碑如何？

⛲ **流动性**：流动性池的 `TVL` 是否足够高，能把价格影响降到最低？

🖱️ **易用性**：用户界面是否好用？

🔐 **安全性**：智能合约是否经过多家机构审计？

🎁 **奖励与功能**：使用交易所或提供流动性有没有忠诚度奖励？你能参与治理投票吗？

在这些方面表现优异的知名平台包括 Uniswap、Curve、Velodrome 和 PancakeSwap。你可以轻松地从一家 DEX 换到另一家，直到找到几个心仪的！本课的任务我们会使用 Velodrome，它是 Optimism 网络上一家成熟的 DEX，易于使用，而且因为在 Layer 2 上，费用要合理得多！
