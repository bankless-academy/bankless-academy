# 分散型取引所とは？

分散型取引所（DEX）は、オンチェーンの取引の場です。エクスプローラーはウォレットの資金を自己保管したまま、他のユーザーと安全に暗号資産を交換できます。このピアツーピアの取引は、誰でも参照できるスマートコントラクトが仲介し、トークンを大量に集めた共同の金庫とユーザーをつなぎます。この金庫が`流動性プール`です。DEX はほぼすべてのブロックチェーンにあり、Ethereum の Layer 1 にも Layer 2 にも存在します。

トークンの交換は`DeFi`を使ううえで欠かせない行為です。DeFi には、他のどんな取引所よりも幅広い種類と用途のトークンがあります。オンチェーンの製品やサービスを使うために買う人もいれば、投資として買う人もいます。企業の株式のように、プロジェクトの方向性を決める議決権を持つトークンもあります。動機が何であれ、DeFi では DEX を日常的に訪れることになります。

その仕組みと、上手な活かし方を学んでいきましょう。

![](https://app.banklessacademy.com/images/decentralized-exchanges/what-is-a-decentralized-exchange-7eed6afb.svg)

# 中央集権型取引所と分散型取引所

中央集権型取引所（Coinbase、Binance、Kraken など）と分散型取引所（Uniswap、PancakeSwap など）で、使われている技術がどう違うのかを見ていきます。

中央集権型取引所（`CEX`）では、ブロックチェーンのエコシステムに直接触れることなく、暗号資産の売買や投資ができます。アカウントは CEX に登録されるため、秘密鍵も資金も CEX の管理下に置かれます。運営方針やルール、そのビジネスモデルのリスクを引き受けることになります。

分散型取引所（`DEX`）では、完全に自己保管のまま暗号資産を取引できます。これこそブロックチェーン本来の目的です。ピアツーピアの仕組みにより、消費者と提供者の両方の立場に立てるようになり、これまで金融の世界の内側にしかなかった機会に手が届きます。ブロックチェーンは透明で、検閲にも強く、誰もアクセスを凍結したり取引を取り消したりできません。ただしハッキングのリスクは残ります。これは後ほど扱います。

![](https://app.banklessacademy.com/images/decentralized-exchanges/centralized-and-decentralized-exchanges-f6f6324c.svg)

# 分散型アプリケーション

DEX は`dApp`の一種です。dApp とはブロックチェーン上で動く分散型アプリケーションを指します。インターネット上のアプリが「分散型」と呼ばれるには、誰でも分け隔てなく使えること、他人の手を借りずに処理が完了すること、そしてコードが公開されていることが必要です。

dApp のサービスはスマートコントラクトが担います。スマートコントラクトとは、オンチェーンの操作を受け取り、決まったオンチェーンの結果を返すコードです。Ethereum Foundation はこれを自動販売機にたとえています。欲しい商品の番号と代金を入れれば、誰かの手を借りずに期待どおりの商品が出てきます。

DEX のスマートコントラクトは、トークンのスワップ、投票、`流動性`の追加や引き出しなど、さまざまな命令を処理します。

![](https://app.banklessacademy.com/images/decentralized-exchanges/decentralized-applications-99447b26.svg)

# 分散型アプリケーション（続き）

DEX も自動販売機と同じ理屈で動きます。ユーザーが入れたトークンを受け取り、望みのトークンを出します。dApp には他にもこんな例があります。

🎟️ **投票 dApp：** ユーザーの投票を指定した対象に割り当てます。

📦 **ブリッジ dApp：** 暗号資産をあるブロックチェーンから別のブロックチェーンへ移します。

🤝 **貸借 dApp：** 条件を満たしたユーザーに融資を行います。

スマートコントラクトは Ethereum 上のアカウントです。アドレスと残高を持ち、送金と命令を受け取ると自動で動きます。DEX とは、複数の機能を備えたプログラム済みの Ethereum アカウントなのです。

`dApp`は通常、ウェブサイトを画面として用意し、その裏にあるスマートコントラクトとのやり取りを助けます。サイトが落ちていても、慣れていればスマートコントラクトに直接アクセスできます。

# 自動マーケットメイカー

従来の市場や`CEX`では、預かり手が`オーダーブック`を使います。買い注文と売り注文が並んだデータベースです。CEX は利用者の注文を別の誰かの注文と突き合わせます。通常は定額や比例の手数料がかかり、非公開の突き合わせ方法が本当に最良の条件を見つけたのかは分かりません。

多くの`DEX`は「自動マーケットメイカー」（`AMM`）技術を使います。トークンのスワップで最も一般的な設計で、公開されたアルゴリズムが価格を決めます。新しい DEX にはオーダーブックやインテント方式を使うものもあります。AMM のアルゴリズムはオープンソースなので、誰でも理解し、複製し、改良できます。それが健全な競争と絶え間ない革新につながっています。

AMM は買い注文と売り注文を直接突き合わせるのではなく、`流動性プール`を通して取引を流します。この共同のトークン金庫は、ユーザーの操作に応じてトークンを受け入れ、払い出します。その一つひとつが公開されたブロックチェーン上で確認できます。

![](https://app.banklessacademy.com/images/decentralized-exchanges/automated-market-makers-78ad7439.svg)

# トークンスワップ

ブロックチェーン上の暗号資産の取引を`トークンスワップ`と呼びます。これは AMM の`流動性プール`を使って、ある暗号資産を別の暗号資産に換えるスマートコントラクトの操作です。DEX のスマートコントラクトは、適切な流動性プールを通る道筋、つまり`取引ルート`を組み立て、入れたトークンを目的のトークンに交換します。プールは通常 2 種類のトークンしか持たず、すべての`トークンペア`にプールがあるわけではないため、ルートが複数のプールを経由することもあります。

スマートコントラクトにウォレットへのアクセスを許すには、指定した額（または無制限）まで引き出す権限を与えます。この`トークン許可`があると、信頼できるコントラクトは秘密鍵なしでトランザクションを実行できます。付与にはガス代がかかるので、権限は次回のために開いたままになります。取引用と保管用でウォレットを分ける理由のひとつです。許可の確認と取り消しは[トークン許可を管理する](https://app.banklessacademy.com/lessons/managing-token-allowances)のレッスンで扱います。

![](https://app.banklessacademy.com/images/decentralized-exchanges/token-swaps-41ceb8e1.svg)

# トークンスワップ（続き）

権限と交換の流れを、実際の例で見てみましょう。Optimism ネットワークの大手 DEX である Velodrome で、USDC を OP にスワップする例です。USDC/OP の`流動性プール`はコスト効率が良くないため、この取引は 2 つのプールを経由することがよくあります。

1. まず、Velodrome の該当するスマートコントラクトに、ウォレットから USDC を引き出す権限を与えます。
2. Velodrome にスワップのトランザクションを送信します。
3. トランザクションが承認されます。Velodrome は指定した額の USDC をウォレットから USDC/ETH の流動性プールへ移します。同じ価値の ETH がこの最初のプールから出て、ETH/OP の流動性プールへ移ります。最後に、2 つめのプールから OP がウォレットのアドレスへ送られます。

これでスワップは完了です。USDC は ETH を経由して OP に交換されました。

![](https://app.banklessacademy.com/images/decentralized-exchanges/token-swaps-continued-bad45a9b.svg)

# 流動性とは？

暗号資産の世界で言う流動性とは、その市場がデジタル資産を公正な価格で売買させられる能力のことです。流動性が高いと価格は安定し、低いと価格は荒れます。ユーザーは公正な価格に集まるので、`DEX`はすべての流動性プールで高い流動性を保とうとします。

流動性が高いとは、流動性プールに大量のトークンがあることを指します。通常は 2 種類のトークンが価値で 50/50 に近い比率で入っています。たとえば USDC/ETH のプールは、そのプラットフォームでのこの`トークンペア`のすべての取引をまかないます。
トークンが多いほど、取引が 50/50 の均衡に与える影響は小さくなり、価格が安定しやすくなります。1 回の取引がこの均衡をどれだけ崩すかを`価格インパクト`と呼びます。

エクスプローラーとしては、最良の条件を得るために価格インパクトをできるだけ小さくしたいところです。つまり、高くて偏りのない流動性が望ましいのです。

![](https://app.banklessacademy.com/images/decentralized-exchanges/what-is-liquidity-a88af170.svg)

# 流動性プロバイダー

高い`流動性`を目指すことは DEX の成功に直結します。しかし暗号資産のエコシステム全体の流動性には限りがあるため、各 DEX はできるだけ多くを取り込もうと競い合っています。では、その流動性はどこから来るのでしょうか。

分散型のエコシステムでは、DeFi の住人がプールに流動性を提供し、プラットフォームの TVL（預かり資産総額）を押し上げるよう動機づけられています。プールを通る取引から集まる手数料は、提供した流動性の量に応じて LP（流動性プロバイダー）に配られます。そう、DEX の流動性プールにトークンを貸し出せば、不労所得を生み出せるのです。

`LP`になるにあたって考えるべき点はいくつもあり、今後の教材で扱います。今のところは、DEX の流動性プールに表示される高い APR（年利）は保証されたものではなく、損失もありうると覚えておいてください。

![](https://app.banklessacademy.com/images/decentralized-exchanges/liquidity-providers-4f46eebb.svg)

# プラットフォーム手数料

CEX も DEX もサービスに手数料をかけますし、ブロックチェーンを使うこと自体も無料ではありません。プラットフォームを選ぶときに考えたい 5 つのコストを挙げます。

🏷️ **プラットフォーム手数料：** CEX は自ら取引手数料を決めます。DEX のプール手数料はプールごとに違い、多くは 1% にも満たない水準です。大きな違いは、DEX の手数料はオンチェーンで誰でも確認できることです。

🌐 **ネットワーク手数料：** ブロックチェーンは dApp のトランザクションとは別にガス代を取ります。混雑していない時間帯を狙えば安く抑えられます。Ethereum メインネットのリアルタイムなガス代の目安は [Etherscan.io](https://etherscan.io/gastracker) で確認できます。Layer 2 ならずっと安く、ネットワークごとの比較は [growthepie](https://www.growthepie.com/) で見られます。

📦 **ブリッジ手数料：** CEX もブリッジも、暗号資産を別のブロックチェーンへ移すときに手数料を取ります。CEX は各サイトの案内を確認してください。ブリッジの dApp は確定前に手数料の見積もりを表示します。

💹 **為替レート：** CEX や DEX で法定通貨から直接暗号資産を買うときは、市場のレートとかけ離れていないか気をつけましょう。

🧊 **スリッページ：** 価格は速く動くので、DEX はスワップに変動の余地を持たせます。これが`スリッページ`で、通常 0.5〜2% の範囲で設定できます。その分まで損をする可能性がある一方、低く設定しすぎると取引が失敗します。

取引の前には必ず自分で調べ、そのプラットフォームのコストと引き換えになるものを理解しておきましょう。

# DEX の利点

このレッスンでは理論を多く扱ってきましたが、DEX が自分に向いているのか気になっているかもしれません。おおまかに言えば、次に当てはまるなら分散型取引所は役に立つはずです。

- 🔑 デジタル資産を自分の管理下に置きたい。
- 🔒 CEX の破綻を避け、資産をブロックチェーン上で守りたい。
- ⌛ 暗号資産市場に 24 時間 365 日アクセスしたい。
- 👛 より幅広い暗号資産に触れたい。
- 🤑 流動性の提供に興味がある。
- 🛂 使うプラットフォームごとに登録や`KYC`をしたくない。
- ⚔️ 分散型金融を探索するリスクと報酬を求めている。

とはいえ、DeFi の利用者のほとんどは中央集権型取引所にも口座を持っています。CEX は従来の銀行との出入り口が使いやすく、銀行口座からブロックチェーンへ、またその逆へ簡単に資金を動かせるからです。[Ryan Sean Adams](https://twitter.com/RyanSAdams) はこれを公衆トイレの利用にたとえています。_「入って、用を足して、出る。」_

まず CEX の口座から始めて、操作に慣れながら少しずつ DeFi へ移っていける、という意味でもこれは心強いことです。

# DEX のリスク

DEX の利用にはリスクも伴います。影響の大きいものをいくつか挙げます。

🐞 **スマートコントラクトのリスク：** 監査はバグの可能性を減らしますが、なくすわけではありません。2025 年には、複数の会社の監査を受けていた大手 DEX が、わずかなコードの不具合で 1 億 2,800 万ドルを失いました。最悪の場合、取引額まで失う可能性があります。信頼され、十分に監査されたスマートコントラクトを選びましょう。

💰 **自己保管のリスク：** 秘密鍵の責任をすべて自分で負うということは、盗難や詐欺、シードフレーズの紛失でウォレットごと失う可能性があるということです。だからこそ、複数のウォレットを使い分けてリスクを抑え、シードフレーズの控えを現実世界の安全な場所に必ず保管しておくことが大切です。

🥪 **サンドイッチ攻撃：** スワップのスリッページを高く設定するほど、取引の前後に割り込む者が`サンドイッチ攻撃`を仕掛けてくる可能性が高まります。サンドイッチ攻撃では、設定したスリッページの分まで失うことがあります。この種の攻撃から身を守る方法は今後の教材で扱います。

こうした利点とリスクを踏まえると、次に当てはまる場合は CEX のほうが合っているかもしれません。

- 🎓 暗号資産の旅を始めたばかりで、リスクと報酬を理解している最中である。
- ⚖️ 取引の頻度も金額も小さく、ブロックチェーンの手数料が割に合わない。
- 🏰 自分で責任を負うより、取引所に資金を見てもらいたい。

一部のユーザーは、売買は CEX で行い、保管はブロックチェーン上で行うという併用でリスク全体を下げています。

# DEX を選ぶ

DeFi には数多くの分散型取引所があり、質にも差があります。どの DEX を使うか決めるときは、次の 5 点を確かめましょう。

🥇 **信頼性：** 信頼性、品質、継続性で名の知れた相手でしょうか。

⛲ **流動性：** 価格インパクトを抑えられるだけの`TVL`が流動性プールにありますか。

🖱️ **使いやすさ：** 画面は操作しやすいでしょうか。

🔐 **安全性：** スマートコントラクトは複数の監査人に監査されていますか。

🎁 **報酬と機能：** 利用や流動性提供に対する報酬はありますか。ガバナンスに投票できますか。

この観点で評価の高い名前としては、Uniswap、Curve、Velodrome、PancakeSwap などがあります。お気に入りが見つかるまで、DEX を渡り歩くのは簡単です。このレッスンのクエストでは、Optimism ネットワークで定評のある DEX、Velodrome を使います。使いやすく、Layer 2 なので手数料もずっと現実的です。

# DEX のベストプラクティス

dApp を使う前に、資金を守るために守っておきたい習慣があります。

👩‍💻 dApp のリンクは、プロジェクト公式の X（Twitter）アカウント（金のチェックマーク）か信頼できる第三者で確認し、ブックマークしておきましょう。DeFi の詐欺の多くは偽リンクから始まります。有名な検索エンジンにも紛れ込んでいます。

🔓 オンチェーンで`トークン許可`を与えるときは、取引額までに制限しましょう。今では多くの DEX が、その取引の分だけを対象とする署名ベースの承認を使っています。[トークン許可を管理する](https://app.banklessacademy.com/lessons/managing-token-allowances)を参照してください。

♟️ 長期保管用のウォレットで dApp を触らず、dApp 専用のウォレットを分けて使いましょう。ウォレットの使い分けは[Web3 セキュリティのレッスン](https://app.banklessacademy.com/lessons/web3-security)で扱っています。
