# はじめに

ブロックチェーンにとって理想的な状態は、できるかぎり分散的で、安全で、スケールすることです。しかし、この 3 つをすべてうまく両立させたブロックチェーンは、まだ現れていません。この難題には名前がついています。`ブロックチェーンのトリレンマ`です。

Bitcoin と Ethereum はどちらもかなり分散的で安全ですが、スケールは得意ではありません。ネットワークが混み合うと手数料が高騰し、トランザクションの待ち行列が長くなります。エクスプローラーは、コストを大きく下げて処理速度を上げるさまざまな技術を利用できます。これらをまとめて Layer 2（L2）スケーリングソリューションと呼びます。

`Lightning Network` は Bitcoin で最もよく知られたスケーリングソリューションで、`ペイメントチャネル`という技術で当事者間の支払いをスケールさせます。Ethereum は複数の L2 に処理を任せてトリレンマを緩和し、2024 年にメインネットへ追加された安価で一時的な`ブロブ`保存領域がそれを支えています（かつて計画された「シャーディング」の軽量版です）。

![](https://app.banklessacademy.com/images/layer-2-blockchains/introduction-c1f2c88f.svg)

# ペイメントチャネル

Bitcoin のブロックチェーンでは、Lightning Network が双方向のペイメントチャネルを使い、メインチェーン上でトランザクションを出さずに BTC をやり取りできるようにします。

この仕組みでは、2 人のユーザーが互いにチャネルを開きます。チャネルは必ず 2 者間ですが、つながったチャネルの網を経由すれば、離れたユーザーへも支払いを中継できます。チャネルを開いてから閉じるまでの間、当事者どうしで資金を動かせます。各参加者の小さな台帳の記録は双方が署名した後に更新されるため、通常は両者のノードがオンラインである必要があります。
チャネルはいつでも閉じられます。どちらかが最新版の台帳をブロックチェーンに公開するだけです。

ペイメントチャネルは高度な`スマートコントラクト`の操作には対応せず、基本的なピアツーピアの送金だけを扱います。

![](https://app.banklessacademy.com/images/layer-2-blockchains/payment-channels-31677af9.svg)

# Ethereum のスケーリングソリューション

Ethereum の開発者は、ネットワークが動き始めた頃から Ethereum 独自のスケーリングソリューションに取り組んできました。

Ethereum コミュニティの多くは、「Ethereum のスケーリングソリューション」を名乗るなら、`セキュリティ`や`分散化`を犠牲にせずに`スケーラビリティ`の弱点を解決すべきだと考えています。ユーザーにとって実際に大切なのは、メインネットより速いトランザクションと安い`ガス`です。競争のために、トリレンマ上のトレードオフをより大きく受け入れる解決策もあります。

Ethereum を特徴づけるのはスマートコントラクトの機能なので、スケーリングソリューションもこれを引き継ぐことが重要です。Layer 2 からお気に入りの `dApp` を使えないなら、速くて安いトランザクションにも意味がありません。

# Layer 1 と Layer 2 をつなぐ

[ブロックチェーンの基礎](https://app.banklessacademy.com/lessons/blockchain-basics)で学んだとおり、ブロックチェーンは`台帳`と呼ばれるデータベースで、暗号技術で守られた時系列のトランザクション一覧を記録します。`L1`ブロックチェーンも L2 スケーリングソリューションも、それぞれ独立したブロックチェーンであり、独自のアドレスとデータのデータベースを持ちます。

異なるブロックチェーンのデータベース間で情報を移すには、`ブリッジ`と呼ばれるインフラを使います。たとえば Ethereum メインネット（や他の `L1`）を 1 つの島、別のブロックチェーンやお気に入りのスケーリングソリューションをもう 1 つの島と考えると、ブリッジは 2 つのデジタルな島を結ぶ高速道路にあたります。

技術はとても複雑ですが、使う人から見れば行き先を選ぶだけの簡単な操作です。

![](https://app.banklessacademy.com/images/layer-2-blockchains/bridging-layer-1-and-layer-2-c219a748.svg)

# サイドチェーン

`サイドチェーン`は Ethereum とは独立して動く別のブロックチェーンですが、`ブリッジ`でメインネットとつながっています。トークンを移すには、メインネットのブリッジコントラクトにロックし、サイドチェーン側で同等のトークンが発行されます。重要なのは、これで資金が Ethereum のセキュリティを得るわけではない点です。ブリッジもサイドチェーンも、サイドチェーン自身のバリデーターに依存します。どちらかが破られれば（2022 年の 6.25 億ドル規模の Ronin ブリッジ事件のように）、ロックされた資金は盗まれます。

サイドチェーンもブロックチェーンのトリレンマからは逃れられません。`ガス代`の安さと速さは、小規模で強力なバリデーター群によるもので、分散性とセキュリティの一部をスケーラビリティと引き換えにしています。

Polygon PoS のようなサイドチェーンは、定期的にスナップショット（「チェックポイント」）を Ethereum に公開します。これで履歴にある種のファイナリティが生まれ、ブリッジから出るときに残高を証明できますが、サイドチェーンの資金がメインネットと同じ安全性になるわけではありません。

![](https://app.banklessacademy.com/images/layer-2-blockchains/sidechains-464f0191.svg)

# ロールアップ

ロールアップ技術を使う Layer 2 プロトコルは、Ethereum メインネットのセキュリティ水準により近い形を保ちます。

サイドチェーンと同じく、ロールアップもメインネットの外でトランザクションを実行します。それらをまとめて 1 つのバッチに「巻き上げ」、そのデータを`ブロブ`という安価で一時的なデータ領域に載せて Ethereum に投稿します。ブロブは 2024 年 3 月の Dencun アップグレードで導入され、L2 の手数料が数セント以下まで下がった主な理由になりました。

ロールアップがメインネットの代わりにトランザクションを処理できると示すには、各バッチのトランザクションが安全で有効だという「説得力のある証拠」を出さなければなりません。この証拠はロールアップに含まれ、Ethereum メインネット上のブリッジコントラクトが検証します。

現在、その証拠を出す方法は 2 つあります。`オプティミスティックロールアップ`と`ZKロールアップ`です。それぞれ詳しく見ていきましょう。

![](https://app.banklessacademy.com/images/layer-2-blockchains/rollups-308dc6c9.svg)

# オプティミスティックロールアップ

Optimism、Base、Arbitrum といった L2 プロトコルは、いずれも`オプティミスティックロールアップ`をスケーリングの土台にしています。この名前は、バッチ内の情報を反証されないかぎり有効とみなす、楽観的（オプティミスティック）な前提に由来します。

悪用を防ぐため、L2 からメインネットへ資金を戻す要求を出すと、通常は数日の待機期間が設けられます。その間、ブリッジのバリデーターは`不正証明`を公開して出金を取り消せます。銀行業界の決済確認に似ていますが、分散型の仕組みです。

注：Across や Relay といった外部のブリッジサービスを使えば、数日ではなく数分で資金を移せます。こうした高速ブリッジは自前の資金プールから立て替えるため、そのスマートコントラクトと資金提供者のリスクを負うことになり、ロールアップ純正のブリッジより信頼する相手が 1 つ増えます。

![](https://app.banklessacademy.com/images/layer-2-blockchains/optimistic-rollups-846aad61.svg)

# ZKロールアップ

`ZKロールアップ`は、ゼロ知識技術を使うロールアップです。`オプティミスティックロールアップ`と違い、不正の証拠を探す特定のユーザーに頼らずにバッチの正しさを確認します。代わりに`有効性証明`と呼ばれる数学的な証明を提出し、Ethereum は計算をやり直さずにバッチ全体が正しいと確かめられます。

大きな利点は`決済時間`、つまり`トランザクションファイナリティ`です。数日の異議申立て期間を待つ代わりに、次の有効性証明が提出され次第、通常は数時間でメインネット上の資金にアクセスできます。名前とは違い、ここでのゼロ知識技術はプライバシーのためではありません。主要な ZKロールアップ上のトランザクションは、Ethereum メインネットと同じくらい公開されています。

ZKsync、Starknet、Linea など、ZKロールアップ技術で Ethereum のスケーリングを進める主要なプロトコルもあります。開発はまだ初期段階ですが、将来性は大きいです。

![](https://app.banklessacademy.com/images/layer-2-blockchains/zk-rollups-9d65de85.svg)

> ℹ️ 「ゼロ知識」という名前ですが、主要な ZKロールアップは Ethereum メインネットと同じく透明です。証明は有効性のためで、プライバシーのためではありません。

- [x] 有効性証明を使い、数日の異議申立て期間を避ける。

> ℹ️ 正解です！数学的な有効性証明が各バッチを確認するので、メインネットでのファイナリティに不正証明の待機期間は要りません。

- [ ] 監視役が期間内に不正証明を出すことに頼る。

> ℹ️ それはオプティミスティックロールアップの仕組みです。ZKロールアップは先に有効性を証明します。

# チェーンをまたぐ dApp の互換性

`オプティミスティックロールアップ`と`ZKロールアップ`を比べるとき、多くのユーザーが気にするのは出金にかかる時間です。ただ、この遅さは外部のブリッジで解消できるので、どのスケーリングソリューションを試すかを決める際の大きな判断材料にはなりません。

多くのオプティミスティックロールアップは「EVM 同等」で、`Ethereum Virtual Machine`（EVM）で動く dApp をそのまま扱えます。EVM 同等なら、メインネットに展開済みのスマートコントラクトをそのまま展開でき、L2 のユーザーもお気に入りの dApp を使えます。

Polygon PoS のようなサイドチェーンも EVM をそのまま動かし、ZKsync、Linea、Scroll など最近の ZKロールアップの多くも EVM 同等かそれに近い状態です。そのため、お気に入りの Ethereum の dApp は L2 エコシステムのほとんどで使えます。

![](https://app.banklessacademy.com/images/layer-2-blockchains/cross-chain-dapp-compatibility-8a372647.svg)

# レッスンのまとめ

Bitcoin や Ethereum のような L1 ブロックチェーンは、いま`ブロックチェーンのトリレンマ`に縛られています。Bitcoin の`ペイメントチャネル`、Ethereum のサイドチェーンやロールアップは、これらのネットワークをスケールさせ、トリレンマを和らげます。

`ブリッジ`は L1 ブロックチェーンと`サイドチェーン`や`ロールアップ`をつなぎます。ブリッジコントラクトの動き方が、つながる側のネットワークの性質を左右します。

サイドチェーンの資金は Ethereum の`セキュリティ`を受け継ぎません。ブリッジしたトークンはメインネットのコントラクトにロックされますが、その安全性はサイドチェーン自身のバリデーターとブリッジコントラクト次第です。これらのチェーンは小規模で強力なバリデーター群を持ち、分散性とセキュリティと引き換えに、速度を上げて手数料を下げています。

ロールアップもサイドチェーンと同じく自分でトランザクションを検証・処理しますが、ブリッジコントラクトが「説得力のある証拠」を求める点が違います。おかげで Ethereum の価値観に沿った`セキュリティ`と`分散化`を保てます。証拠の出し方は 2 通りです。`オプティミスティックロールアップ`はメインネットでの確定まで数日待ち、その間にブリッジのバリデーターが不正を見つけて報告します。`ZKロールアップ`は`ゼロ知識`技術で、トランザクションの正しさを数学的に保証します。

現在は、オプティミスティックロールアップも最近の ZKロールアップも Ethereum メインネットとのスマートコントラクト互換性が高く、メインネットの dApp を簡単に展開できます。速いファイナリティと強い有効性の保証から、ZKロールアップが未来のスケーリングソリューションになると考える人も多くいます。

# Optimism または Base で Layer 2 の旅を始めましょう 🙂

Optimism と Base はどちらも EVM 同等のオプティミスティックロールアップで、エクスプローラーが最初に触れる L2 に向いています。どちらのチェーンでも dApp の使い心地は L1 とほぼ同じで、ただ安く速いだけです。ガスにはどちらも ETH を使います。次のクエストは、Optimism か Base での旅の第一歩です。

どちらのエコシステムも Ethereum の価値観を深く受け継いでいます。Optimism は、Bankless Academy の無料教育のようにエコシステムに価値をもたらす[公共財への資金提供](https://optimism.mirror.xyz/wqk1Yeyn2OhV9paDzbRXvQ0m0JYDu2npbSkMClwk1rY)で知られています。

Optimism と Base はオプティミスティックロールアップを使う場というだけではありません。ブロックチェーンが現実の問題を解き、取引や協力の新しい形を開けることを示しています。それは、私たち全員が楽観的（オプティミスティック）になれる理由です。🙂
