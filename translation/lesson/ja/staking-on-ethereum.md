# Ethereum でのステーキング

エクスプローラーの皆さん、次のレッスンへようこそ！

今日は「ステーキング」という仕組みを見ていきます。デジタルの資産を育てる、シンプルな方法の一つです。

`ステーキング`は Bitcoin ネットワークの`マイニング`に似ています。どちらも、報酬と引き換えに参加者がブロックチェーン上のトランザクションを処理する仕組みです。ネットワークを`分散型`に保つ役割も同じです。

ただし、マイニングとステーキングには大きな違いがあります。Ethereum のステーキングでは、他人と競うための高性能なコンピューターは要りません。Ether（ETH）をネットワークの`スマートコントラクト`にロックするだけで、Ethereum は動き続け、報酬も受け取れます。

![](https://app.banklessacademy.com/images/staking-on-ethereum/staking-on-ethereum-50472cf7.png)

# Ethereum は守り手を求めています！

`ステーキング`は「インターネットの債券」のようなものだと考えてみてください。

国債で政府を支えると利回りが得られるように、Ethereum を支えると報酬が得られます。さらに国債と同じく、ステーキングは自分の価値観や望む世界に金銭的な支持を示す方法でもあります。

Ether をステークすると、それは Ethereum のトランザクションを処理する`バリデーターノード`に割り当てられます。ステークされる Ether が増えるほど、Ethereum が持てるノードは増えます。ノードが増えるほど、Ethereum はより`分散型`になり、安全になります。

`ステーカー`になることは、**Ethereum の守り手になること**です。

では、ステーキングの仕組みを詳しく見て、今日から気軽に、低コストで始められる方法を探しましょう。

装備を持って、出発です！

![](https://app.banklessacademy.com/images/staking-on-ethereum/ethereum-wants-you-fd40b9e5.png)

# ブロックチェーンのセキュリティ

`バリデーターノード`は、Ethereum の安全で正当な経済の要です。ブロックチェーンを`不正`から守ります。

ブロックチェーンの世界での不正とは、残高を書き換えたり、存在しない暗号資産を作り出したりすることです。Ethereum はすべてのトランザクションが有効であることを確かめ、誰も他人より強い力を持たないようにしてこれを防ぎます。この公平さは`信頼できる中立性`と呼ばれ、とても大切です。ごまかしと不信のある経済に加わりたい人はいませんし、そうした経済はいずれ崩れるからです。

健全なブロックチェーンでは、バリデーターノードは一つの目標を共有します。**ブロックチェーンの状態について、ネットワーク全体で分散的な合意に達すること**です。ノードはトランザクションを調べ、これまでの履歴と照らし合わせ、有効かどうかを投票します。ノードの`コンセンサス`で有効と認められたトランザクションが、ブロックチェーンに追加されます。

![](https://app.banklessacademy.com/images/staking-on-ethereum/blockchain-security-7f2149fe.svg)

# プルーフオブステーク

`バリデーターノード`を動かしたい人は、最低 32 ETH をロックしなければなりません。かなりの金額です。（2025 年以降、1 つのバリデーターがより多くの残高を持てるようになり、ステーカーは待ち行列を通じていつでも解除できます。）ネットワークに大きな金銭的な「ステーク」を差し出す代わりに、`ノードオペレーター`は Ethereum のトランザクションのブロックを提案し、確認し、報酬を得られます。ブロックとは、ネットワークに送られたトランザクションのまとまりだと考えてください。

ネットワークの`コンセンサスメカニズム`が、次のブロックを提案するバリデーターノードをランダムに選びます。その判断は他のノードが二重にチェックし、正直さを保ちます。ノードがブロックの提案に成功すると、その`ステーク`は増えます。

![](https://app.banklessacademy.com/images/staking-on-ethereum/proof-of-stake-49c358ed.svg)

# スラッシング

ノードの不正が証明されると、たとえば矛盾する 2 つのブロックに署名すると、そのステークは`スラッシング`の対象になり、Ether の一部を失います。遅れたりオフラインになったりするのはスラッシングではなく、小さなペナルティで済みます。こうしてステークされた Ether は保証金の役割を果たし、ノードは正直に、Ethereum を滞りなく動かすよう動機づけられます。

攻撃者が Ethereum で不正を承認するには、バリデーターノードの過半数、つまりステークされた Ether の過半数を支配しなければなりません。幸い、ふだんのユーザーがステーキングに参加していれば、そうはなりません。ネットワークを`分散型`に所有することが、意思決定の力を分け合わせます。

![](https://app.banklessacademy.com/images/staking-on-ethereum/slashing-ccabe137.svg)

# トランザクションの検証

`プルーフオブステーク`のコンセンサスで、ノードがどう合意に達するのかを順に見ていきましょう。

1. **ステーキング：**`ノードオペレーター`がネットワークに 32 ETH をロックし、`バリデーターノード`の運用を始めます。
2. **ブロックの構築：** ユーザーが送ったトランザクションを、`ブロックビルダー`が`ブロック`にまとめます。
3. **提案者の選出：** アルゴリズムが、次にブロックチェーンへ追加するブロックを提案するバリデーターノードを選びます。
4. **ブロックの提案：**`ブロックプロポーザー`が候補のブロックを確認して 1 つ選び、有効なら`アテステーション`を与えます。
5. **相互検証：** 他のバリデーターがそのブロックを二重にチェックし、有効ならアテステーションを与えます。無効なブロックは無視され、チェーンに入ることはありません。
6. **ブロックの追加：** 有効なブロックが Ethereum のブロックチェーンに追加されます。
7. **報酬：** ブロックプロポーザーは`ブロック報酬`とトランザクションのチップを得ます。他のバリデーターにも報酬があります。

# イーサノミクス

バリデーターノードに Ether を提供する見返りに、ステーカーはその報酬の一部を受け取ります。

ノードが受け取る報酬はエコシステムのさまざまな要因で決まり、変わります。簡単に言えば、報酬はトランザクション手数料の一部と、新しいブロックで発行される少量の Ether です。

年利は時期によって変わり、これまではステークした Ether に対して数パーセント程度でした。正確な額は、主に 2 つの要因で決まります。

- 📈 **ネットワークの活動：** おおまかに言えば、利用が少なければ報酬は下がり、多ければ上がります。
- 👥 **バリデーターノードの数：** 参加者が増えるほど報酬は細かく分かれます。

利回りは、Ether をどうステークするかによっても変わります。選択肢を見ていきましょう。

![](https://app.banklessacademy.com/images/staking-on-ethereum/ethernomics-33407ddc.svg)

# ステーキングの種類

`バリデーターノード`を動かすには通常 32 ETH のロックが必要ですが、新しいステーキングの方法のおかげで、誰でも Ethereum の守り手になれるようになりました。

Ethereum を守る方法は 3 つあります。

- 📡 **ソロステーキング：** 自分でバリデーターノードを動かす。
- ⛲ **ステーキングプール：** 他のステーカーと組んで一緒にノードを動かす。
- 🏦 **中央集権型取引所でのステーキング：**「暗号資産の銀行」のノードに参加する。

どの方法も、始めるのに必要な技術の知識の程度が違い、それぞれのリスクもあります。

`秘密鍵`を自分で持つことに抵抗はないけれど 32 ETH はない、という場合は、ステーキングプールへの参加を考えてみてください。

まだ暗号資産の`自己保管`に抵抗があるなら、中央集権型取引所のステーキングを見てみましょう。その間に[ウォレットの基礎](https://app.banklessacademy.com/lessons/wallet-basics)のレッスンを受けて、思い切って暗号資産を自分のものにしましょう。

# ネットワークの中央集権化

**1 つの主体のもとに多くのノードが集まるステーキングは、Ethereum の中央集権化を進めます。**

Ethereum を`バリデーターノード`がつながった網だと想像してください。ノードが 1 つか少数の主体に集中すると、網全体が偏り、危うくなります。そうならないためには、独立した接続点がたくさん必要です。

1 つの主体が多くのノードを支配するのはよくないことです。トランザクションのブロックが、網の中央集権化した部分を通らされるからです。その主体は不正なブロックを承認したり、有効なブロックを拒んだりできます。これは Ethereum の`信頼できる中立性`を壊します。

守り手として、私たちは網の均衡と`分散型`のあり方を保つステーキングを選ぶ必要があります。

初心者が自分でバリデーターノードを動かすには壁がたくさんあります。代わりに、分散的なステーキングを始めやすい方法、`ステーキングプール`を見てみましょう。

# ステーキングプール

`ステーキングプール`の何よりの利点は、すべてが`スマートコントラクト`で運営されることです。他のステーカーと直接会う必要も、信頼する必要もありません。ただし、スマートコントラクトは信頼することになります。

ステーキングプールを用意するのは`ステーキングプロバイダー`、世界中のステーカーをつなぐデジタルのプラットフォームです。プールでは、`ノードオペレーター`が 32 ETH の一部をステークしてノードを動かし、残りの Ether を他の参加者が出します。ノードオペレーターは、その働きに対して上乗せの利回りを得ます。

残りの参加者には「リキッドステーキングトークン」（LST）が渡され、プールへの参加を表します。この`トークン`は、プールにステークされた Ether の持ち分を表します。保有者は持ち分に応じた報酬を受け取り、いつでもステークを引き出せます。

LST（たとえば Rocket Pool の rETH）を持つだけで、ステーキングプールの持ち分を所有できます。そう、Ether が Ethereum を分散化しながら、ステーキング報酬を稼いでくれるのです。

![](https://app.banklessacademy.com/images/staking-on-ethereum/staking-pools-46c96251.svg)

# リキッドステーキングトークン

`LST` の一番よいところは、Ether をステークして利回りを得ている間も、`流動性が高い`形のままでいられることです。

ここでの「流動性が高い」とは、エコシステムの中を動き回れるという意味です。ステーキングプールの持ち分を持ちながら、それをお金のように使えるところを想像してみてください。LST は交換したり、ローンの担保にしたり、`リステーキング`のプラットフォームに預けたりできます。リステーキングは、追加の利回りと引き換えに追加のリスクを取る、任意の戦略です。

LST がすばらしいのは、ステークされた Ether への入り口を広げるからです。ステーキングプールには Ether を預ける最低額（0.01 ETH 前後）があることが多いのですが、LST なら、お気に入りの`分散型取引所`でもっと小さな単位のステーク済み Ether を買えます。

# またしてもネットワークの中央集権化！

ステーキングプールと LST にも、ステーキングの方法と同じ落とし穴があります。**それぞれ中央集権化と分散化の度合いが違うのです。**

Rocket Pool のようなステーキングプロバイダーは、誰でもどこからでもステーキングプールの`ノードオペレーター`になれるようにしています。新しいノードオペレーターが 32 ETH のステークを積み上げるのを助け、Ethereum の分散化につながります。一方、限られた関係者にしかノードを任せないプロバイダーもあり、ステークされた Ether が集中するリスクがあります。

ある主体がステークされた Ether 全体の 33% を超えて支配すると、ネットワークに問題を起こせます。50% になれば、Ethereum の`信頼できる中立性`を本気で脅かします。

大手のステーキングプロバイダーには、その 33% に近づいたところもあります。ステークを多くのプロバイダーに分散させることが、ネットワークの安全を守ります。

Ethereum を守るには、調べることが欠かせません。`ステーキングプール`を使う場合でも、分散化を支える選び方が必要です。

# rETH、分散的なステーキングへの道

ステーカー、つまり Ethereum の守り手になるときが来ました。
今日のクエストでは、Rocket Pool で`ステーキングプール`の持ち分を手に入れます。

🪙 やることは簡単です。Rocket Pool の`リキッドステーキングトークン`、**rETH** をミントするか買うだけです。

ステーキングの旅の第一歩として、`バリデーターノード`に資金を提供してブロックを処理してもらい、その見返りに Ether の報酬を受け取ります。

**注：** rETH では、ステーキング報酬はトークンの価値に上乗せされます。今日 1 rETH を持っていれば、1 年後も 1 rETH のままです。ただ、その価値が上がっています。

クエストの成功を祈ります、エクスプローラー！Ethereum の分散的な未来への貢献が、大きく報われますように。
