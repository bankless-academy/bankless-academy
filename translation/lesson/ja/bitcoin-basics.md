# お金の短い歴史

お金は、ビーズや貝殻、石でモノやサービスを交換していた大昔から、社会に欠かせないものでした。

ただ、初期の通貨には問題がありました。新しいお金を見つけたり作ったりするのが簡単すぎたのです。量が増えるほど価値は下がるので、みんなのお金は少しずつ目減りしていきます。価値を保つには、手に入れにくい通貨が必要でした。

やがて金や銀が使われるようになります。最大の利点は、無限には存在しない点でした。誰かが流通するお金の量を大きく増やすことはできません。この`希少性`が、お金の価値を支えました。

社会が大きくなると、政府の中央銀行が金や銀で規格化された硬貨を発行しました。こうした通貨は見分けやすく数えやすく、価値の保存手段としても強いものでした。

![](https://app.banklessacademy.com/images/bitcoin-basics/a-brief-history-of-money-b5126abd.svg)

# お金の短い歴史（パート 2）

紙幣が登場すると、通貨は金に「裏付けられる」ようになりました。お金の価値は、保管された貴金属の一定量と直接結びついていました。

そして 20 世紀、この「`金本位制`」が終わりを迎えます。

貴金属は世界中の通貨から少しずつ切り離されました。各国の経済が、保有する金の量を超えて成長できるようにするためです。中央銀行は通貨を作るのに金を必要としなくなり、経済に必要と判断した分だけ新しいお金を作れるようになりました。供給量を握ることで、その価値も左右できます。

デジタル時代に入り、電子的な通貨が現金の大部分を置き換えました。商業銀行にお金を預けることで、クレジットカードや決済アプリの便利さを手にしました。手軽で安全な一方、私たちとお金のあいだに営利企業が入ることにもなります。

![](https://app.banklessacademy.com/images/bitcoin-basics/a-brief-history-of-money-part-2-3f9be5ac.svg)

# 問題点

今の金融システムの問題は、自分のお金を自分で制御できていないことです。そのせいで、何を貯めて何を使うかを自由に決めにくくなっています。

国の`金融政策`を担う`中央銀行`は、新しいお金をいくらでも生み出せます。この`希少性`のなさが、お金の価値を毎年少しずつ削っていきます。価値が読めず目減りするお金は、使うことを促します。**「毎年価値が下がるなら、貯める意味はあるのか。今使ってしまおう」** 💸

日々の貯蓄や支払いに使う`商業銀行`も、私たちの使い方に影響します。`カストディアン`である銀行は、トランザクションを止めたり、資金を凍結したりできます。暗号資産の購入を顧客に禁じた銀行もあります。**銀行がいつでも生涯の蓄えを凍結できるなら、そのお金は本当に自分のものでしょうか。** 💸

---

お金がふたたび経済的な自由を支えるには、時間のなかで失った 2 つの性質を取り戻す必要があります。

- 💎 **価値**：時間が経っても価値を確実に保てること。
- ✊ **所有**：自分で簡単に保管し、守れること。

この 2 つがそろって初めて、自由に貯め、自由に使う力が戻ります。

# Bitcoin の登場

`サトシ・ナカモト`は、お金は一部の人だけが握るには重要すぎると考えました。誰にとっても公平で信頼できるお金を作ろうとしたのです。

こうして登場したのが Bitcoin（`BTC`）です。従来の銀行システムの外側で動くデジタル通貨です。

- ⛓️ `ピアツーピア`です。人と人を直接つなぎます。`ブロックチェーン技術`で自動化され、保管や送金を仲介する機関が要りません。支持者は「支配者のいないルールの集まり」と呼びます。
- 💎 `希少`です。新しいお金を無限に発行する中央銀行がないため、金融政策は安定していて予測でき、長期の貯蓄を尊重します。
- ✊ `自己保管型`です。送金や保管を担う機関なしで持てます。誰が何を持っているかはネットワークが記録し、`秘密鍵`が証明します。コインを動かせるのは鍵を持つ人だけです。

こうした性質から、Bitcoin は「デジタルゴールド」と呼ばれています。

![](https://app.banklessacademy.com/images/bitcoin-basics/enter-bitcoin-b108517c.svg)

# デジタルゴールド：希少性

📉 上がり続ける物価についていくのが大変だと感じませんか。

Bitcoin の希少性とは、存在できる枚数に上限があることです。上限は 2,100 万枚。この`最大供給量`はコードに書き込まれ、金と同じように Bitcoin を希少にしています。

新しいコインは`暗号資産のマイニング`という手間のかかる作業を通じて`流通供給量`に加わります。およそ 4 年ごとに新規発行は半分になり（`半減期`）、上限に近づくにつれてゼロへ向かいます。マイナーは次第にトランザクション手数料に頼るようになります。

Bitcoin の固定された`金融政策`は、長期の価値保存に向いています。2024 年以降は規制されたファンド（`現物 ETF`）を通じて従来型の投資家も Bitcoin を持てるようになり、「デジタルゴールド」としての役割が強まりました。

短期的な価値は、市場の思惑で大きく揺れ続けます。

![](https://app.banklessacademy.com/images/bitcoin-basics/digital-gold-scarcity-8c8905f7.svg)

# デジタルゴールド：自己保管

🧊 気に入らない送金をしたという理由で、銀行に予告なく資金を凍結されたことはありませんか。

---

民主主義の社会では、所有は保護された人権です。自分の生活を自分で決める力と自由を与えるからです。生きる手段が企業や機関の判断に左右されるなら、自由には動けません。

お金も、財産も、身元さえもデジタル化が進むなか、私たちの生活そのものがデジタルになりつつあります。だからこそ、守り方を学ぶ必要があります。

Bitcoin の`自己保管`は、`カストディアン`の手が届かない、本当のデジタル所有をもたらします。コインはアプリやサイトに保管されているわけではありません。所有はネットワークが記録し、`秘密鍵`が証明します。鍵を自分だけのものにしておけば、デジタルゴールドの金庫を開けられるのは自分だけです。

この所有の仕組みが、世界のどこでも、いつでも、デジタルの富を完全に自分で管理する力を与えます。

# Bitcoin ネットワーク

ここからは Bitcoin を動かすエンジンを見ていきます。
**Bitcoin ネットワーク**です。

Bitcoin は、世界中の数千台のコンピューターが支える共有ネットワークの上で動いています。どのコンピューターも運営を保つ役割を担い、ネットワークはそれらによって存在しています。1 台が不正なトランザクションを処理しても、ほかのコンピューターが正します。

つまり、攻撃者が狙える単一の急所がありません。ネットワークを支配するには、過半数のコンピューターを乗っ取る必要があります。

この守り方を`分散化`と呼びます。1 つの中心的な集団から、多数の小さな参加者へ制御を移すことです。暗号資産のネットワークが事実上止められないのは、このためです。

![](https://app.banklessacademy.com/images/bitcoin-basics/the-bitcoin-network-eda52e60.svg)

# Bitcoin のマイニング

Bitcoin ネットワークには中央銀行がないため、`分散型`の参加者に頼っています。`マイナー`と呼ばれる参加者は、トランザクションを絶えず確認し、「データベース」である`ブロックチェーン`に追加していきます。

不正からネットワークを守るには、マイナーが働き続け、正直でいる動機を持つことが大切です。マイナーは互いの結果を何度も確認し合い、その働きに報酬を受け取ります。Bitcoin のトランザクションを送るとき、私たちは少額の手数料を払い、それは処理したマイナーに渡ります。マイナーは「ブロック報酬」と呼ばれる新しい Bitcoin も受け取ります。

この報酬が、2,100 万 `BTC` という`最大供給量`の枠内で、`流通供給量`をゆっくり増やしていきます。

新しいコインがゆっくり、予測できる形で増えることが、Bitcoin を従来の通貨と分けています。すべては`中央銀行`にいる少人数ではなく、コミュニティが承認したコード（「支配者のいないルール」）と分散した参加者が動かします。

![](https://app.banklessacademy.com/images/bitcoin-basics/bitcoin-mining-9b8a77ea.svg)

# Bitcoin のトランザクションを送る

Bitcoin のトランザクションやマイニングの正確な仕組みは、かなり複雑になります。とはいえ、Bitcoin を使って送ること自体は簡単です。

今日は流れを簡単に見てみましょう。

1. `暗号資産ウォレット`からトランザクションを送り、友人のウォレットアドレスに 0.1 `BTC` を送金します。
2. マイナーがトランザクションに誤りがないか確認します。ほかのマイナーがその結果を再確認します。
3. 承認されると、トランザクションは`ブロックチェーン`という「データベース」に追加されます。
4. 友人のウォレットに 0.1 BTC が届きます。

# お金の革新

このレッスンでは、Bitcoin の希少性が価値の保持を助けること、そして資産を機関に預けることが完全な所有を手放すことを意味するのを見てきました。

Bitcoin は単なるお金の道具を超えて進化しました。`分散型のお金`の革命を後押しする存在です。この動きは、お金をめぐる力と制御を使う人の側に配ることで、従来の金融システムを作り直します。

お金を分散させ、`カストディアン`をなくすと、次のことができます。

- 💵 世界中の市民が守る、24 時間 365 日の世界市場をつくる。
- 🛠️ 銀行が届かない地域に金融の道具を届ける。
- 🤝 `ピアツーピア`の技術で、仲介機関の無駄を避ける。
- 🔎 制度的な不平等、不正、市場操作を減らす。
- ⚖️ `機会の平等`をお金の仕組みに組み込む。
- 🌐 デジタル時代にふさわしい本当の所有を確立する。

新しいお金の時代は民主主義の基本的な価値を掲げ、世界中の市民の暮らしを良くしようとしています。そこにはみなさんも招かれています。
