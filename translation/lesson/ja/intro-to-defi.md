# DeFi とは

DeFi は decentralized finance（`分散型`金融）の略で、公開`ブロックチェーン`のネットワーク上で動く金融商品、プロトコル、アプリケーションのエコシステムです。

DeFi は従来の金融サービスに代わる、確立されたオープンな選択肢です。暗号資産を働かせるための道具がそろっています。中央集権型取引所で暗号資産を買うだけでは得られない機会が広がり、誰でも分散的でバンクレスな暮らし方を築けます。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-defined-759c5922.svg)

# なぜ DeFi なのか

DeFi は、インターネットにつながる人なら誰でも高度な金融ツールを使えるようにします。投資、取引、貸し借り、そしてステーキングです。

しかも透明でオープンです。銀行が閉じた扉の向こうでお金を扱うのとは違い、誰でもコードを読み、コントラクトが書いてあるとおりに動くことを確かめられます。

間に立って参加者を選ぶ機関もありません。誰も入場を断ったり、口座を凍結したり閉じたりできません。

# 利回りを得る

多くの `DeFi` プロトコルでは、暗号資産を働かせて利息などの報酬を得られます。ふだんは銀行や金融機関が必要な金融商品を、書類や審査といった面倒なしに使えます。

DeFi は無料ではありません。トランザクションごとに少額のネットワーク手数料がかかり、手数料を取るプロトコルも多くあります。ただ、こうした費用はたいてい安く、完全に透明です。銀行の間接費はなく、アクセスや収益を止められる機関もありません。だから DeFi は人気があります。

![](https://app.banklessacademy.com/images/intro-to-defi/earning-yield-bc952747.svg)

# DeFi でできること

`DeFi` のトランザクションは`パーミッションレス`です。つまり、誰でも資産の売買や交換に使える公開`ブロックチェーン`の上で行われます。第三者が活動を管理したり監視したりすることはありません。こうしたやり取りを担うのが、DApp と呼ばれる分散型アプリケーションです。

`dApp` と DeFi のプラットフォームは、世界中で 24 時間 365 日動いています。多くは`ステーブルコイン`、つまりドルの価値を一定に保つよう設計されたトークンを使います（[ステーブルコインを理解する](https://app.banklessacademy.com/lessons/understanding-stablecoins)のレッスンをご覧ください）。ここでは DeFi でよく行われる 4 つの活動、投資、取引、貸し借り、ステーキングを紹介します。

![](https://app.banklessacademy.com/images/intro-to-defi/what-you-can-do-with-defi-e1e865b5.svg)

# 投資

最もよくある `DeFi` のトランザクションは、将来値上がりすることを期待して暗号資産を買うことです。これを投資と呼びます。

HODL は暗号資産を長く持ち続けることを指す言葉です。由来は説が分かれ、HOLD の打ち間違いだとも、**H**old **O**n for **D**ear **L**ife（必死にしがみつく）の略だとも言われます。

DeFi では、中央集権型取引所（CEX）に上場する前の新しいコインやトークンに、いち早く触れられることもあります。

![](https://app.banklessacademy.com/images/intro-to-defi/investing-7c8b44ed.svg)

# 取引

分散型取引所（DEX）は、暗号資産のトークンやコイン同士の交換レートを表示し、買い手と売り手を引き合わせて通貨を交換できるデジタルの市場として働きます。

DEX での取引では、当事者どうしが知り合いである必要も、信頼し合う必要もありません。DEX を相手に取引しているように見えるかもしれませんが、たいていの場合、DEX は`流動性プール`を作り、2 人のトレーダーの`ウォレット`の間の取引を`パーミッションレス`に成立させています。

![](https://app.banklessacademy.com/images/intro-to-defi/trading-67935721.svg)

# だから何が変わるのか

資産の多さに関係なく、誰でも取引し、市場に参加できます。オンチェーンのプロトコルを通じて、誰でもポジションを持つことも手放すこともできます。

# 貸し借り

DeFi の貸し借りでは、銀行などの仲介機関なしにお金を借りられます。貸し借りは`ピアツーピア`で行われ、`dApp` が貸し手と借り手を直接つなぎます。貸し手は利息を受け取り、借り手は元本と利息を返します。

借りるには、まず借入額より価値の高い暗号資産を`担保`として預けます。担保の価値が下がりすぎると、自動的に売却されて返済に充てられます。これを`清算`と呼び、信用審査なしでも DeFi のローンが安全に成り立つ仕組みです。

![](https://app.banklessacademy.com/images/intro-to-defi/lending-borrowing-b7d58dfa.svg)

# ステーキング

`ステーキング`は貸し出しと一緒に語られがちですが、別のものです。借り手がいません。`イーサ`をロックして Ethereum ネットワークの安全を守り、その見返りにネットワークが報酬を払います。

ステークした資金は一定期間ロックされることがあり、不正を働いた`バリデーター`はステークの一部を失います。だから正直でいることが得になります。中央集権型取引所もステーキングを提供していますが、DeFi なら資産を自分で管理したまま、より多くの選択肢を持てます。詳しくは [Ethereum でのステーキング](https://app.banklessacademy.com/lessons/staking-on-ethereum)のレッスンをご覧ください。

![](https://app.banklessacademy.com/images/intro-to-defi/staking-8dbafcb8.svg)

# DeFi の弱点

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-da1fdb68.svg)

**ハッカー**

お金と技術があるところには、システムを破ろうとする人が現れます。DeFi のプロトコルと利用者は狙われやすいので、セキュリティの習慣が大切です。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-d533aeef.svg)

**リスク**

DeFi はコード、つまり`スマートコントラクト`の上で動きます。コードの誤りや抜け穴があれば、資金を抜き取られることがあります。市場のリスクもあります。価格が下がればローンは清算され、`ステーブルコイン`が安定した価値を保てなくなることもあります。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-0070f0e1.svg)

**救済がない**

サポート窓口はなく、何か起きても訴えられる会社も官庁もありません。失った資金や盗まれた資金は、たいてい取り消せず、返ってきません。

# Knowledge Check 8

DeFi のリスクはどれですか？

- [ ] リスクはない

> ℹ️ もう一度！DeFi にはハッカーやコードの悪用といった実際のリスクがあり、問題が起きても訴える相手がいません。

- [ ] 銀行にローンを断られる

> ℹ️ もう一度！DeFi に銀行はありません。貸し借りはピアツーピアでパーミッションレスです。

- [ ] 中央の管理者に資金を凍結される

> ℹ️ もう一度！DeFi には資金を凍結できる中央の管理者がいません。リスクはコードの誤りなど別のところにあります。

- [x] コードに誤りがあるかもしれない

> ℹ️ 正解です！DeFi はコードの上で動くので、誤りや抜け穴が悪用されることがあります。
