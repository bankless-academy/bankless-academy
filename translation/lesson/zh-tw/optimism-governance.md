# 老問題，新工具

現代技術極大地改變了人類的視角和互動方式。 在世界舞臺上，在無國界的網路空間中，我們需要新的協調模式，在這個地球村裡共存共榮。

`DAO` （去中心化組織）的願景是簡化大量合作者之間的辯論，解決問題 —— 無論是在網際網路上，還是線上下的當地社群，亦或是國際範圍內。 具體做法如下：

- 激勵參與者共同承擔使命。
- 創新的投票、 授權和 `否決` 機制。
- 使用區塊鏈技術，減少人為錯誤，或是減少被技術劫持的可能性。

![](https://app.banklessacademy.com/images/optimism-governance/old-problems-new-tools-df0ceb84.svg)

# 網路治理

如同傳統擁有資源和廣泛參與者的傳統民族國家一樣，DAO 使用治理流程來指導其資源的部署，實現其使命。 它就像一個市政廳，但卻是`非同步`的、全球性的，以程式碼為部分中介。

📜 **提案：** 首先是治理提議和社群討論。 提案根據公眾的反饋意見進行更新。 任何人都可以提交提案，或對提案進行點評。 這是"`DAO`"的"去中心化"部分。

🗳️ **投票：** 提案進入投票階段 —— 透過`鏈上治理`的透明、抗審查程式進行。 開票和關票沒有任何人工協助，全部由程式碼進行操作。 這是"`DAO`"中的"自治"部分 —— 這樣高品質的設想最終將覆蓋整個治理過程。

🛠️ **實施：** 經批准的提案將應用於網路，必要時由各種受激勵的開發者們實施。

# Optimism 願景

Optimism 的使命是：透過構建 `Layer 2` 網路來擴充套件以太坊。 它是以太坊生態系統的一部分，但費用更低，交易更快，同時保持了以太坊的高標準安全性。 關鍵屬性如下：

🏕️ **公共產品：** 高度重視資助和建設鏈上公共產品。 公共產品是一種惠及社群內每個人的產品，一個人使用它並不會減少其他人的使用機會。 正是因為 Optimism 對公共產品的支援，您在 Bankless Academy 的免費教育才得以實現！

🧑‍🤝‍🧑 **社群治理**：網路由社群領導。

🏠 **自由市場：** 不僅是以太坊 `區塊空間`的延伸，也是以太坊原則的延伸。 它旨在擴大以太坊的無准入性、開源、抗審查市場。

Optimism 旨在成為一個"網路空間區"，直接為其公民提供服務，並由其公民管理！

# 漸進式去中心化

許多偉大的區塊鏈專案都是從一箇中心化小組開始的。 這讓專案在建設和支出方面有了重點，但僅僅是去中心化是不夠的， `DAO`需要**更多的承諾**。 在 Optimism，創始人（founders）、網路（network）和社群（community）的概念如下：

- 🏦 **Optimism 基金會**：網路創始者們。 他們啟動生態系統，提供初始資源，並在最終解散之前充當社群管理者。
- 🌐 **Optimism 網路：** 區塊鏈上自動執行的程式碼 —— 智能合約和使用者輸入處理。
- 👬 **Optimism 集體**：治理社群；由不同的全球參與者組成。 他們負責生態系統的長期所有權和管理。 “DAO”這一術語則同時包含了集體和網路。

律法檢查與制衡機制，如集體有權罷免基金會成員，確保**網路所有權緩慢轉移至社群**。

# 新經濟

Optimism `L2` 經濟的中心是 **"Optimistic 飛輪"**。 這種經濟迴圈帶來了收入以及網路的增長，並逐步實現 Optimism 的使命。

1. 使用者和`dApps`需求網路`區塊空間`。
2. 該網路透過交易費創收。
3. 這些稅收的一部分將獎勵給提供有影響力的公共產品基礎設施的建設者。
4. 網路使用者可獲得免費資源和服務，提高 OP 區塊空間的價值。

有了更有價值的鏈上基礎設施，對 Optimism 區塊空間的需求就會增加，迴圈往復！

![](https://app.banklessacademy.com/images/optimism-governance/a-new-economy-cd0a0ca1.svg)

# 激勵公共產品

如您所見， 公共產品基礎設施是 Optimism 的核心。 但挑選值得資助的專案並不是一件簡單的事。

就此 Optimism 採用 "**影響（Impact）= 收益（Profit）**"的方法。 然而，影響是難以預料的。 提供資金的機構不進行預測，而是定期審查現有專案，並根據歷史業績分配追溯供資。

正如 Vitalik Buterin 所說， _"就 過去 有用的東西達成一致意見比就 將來 有用的東西達成一致意見更容易"。_

這種分配模式被稱為"**追溯性公益資助（Retroactive Public Goods Funding**）"，或 "**RetroPGF**"。 這種資助機制激勵 Optimism 的樂觀思想家們建設服務於全人類的公共產品。 它將我們從傳統資本主義經濟的價值榨取思維中解放出來。

![](https://app.banklessacademy.com/images/optimism-governance/incentivizing-public-goods-78035b95.svg)

_"這是一種獎勵早期合作者的演算法，他們為公共產品的繁榮創造了條件。 在這樣的未來裡，對公共產品的早期投資得到了認可。 這也是一種心態：樂觀主義將佔據上風，更好的系統是有可能被創造出來的，人類將因合作的革命而得到回報"。_

# 隆重介紹：治理院

Optimism 集體由兩個議院組成，在管理網路方面，每個議院都有獨立的職責，也有共同的職責。

 **代幣院（The Token House**）負責管理網路升級、獎勵和（國庫）財政。 其利益相關者結構激勵網路經濟的發展，併為利益相關者創造價值。 議院還負責維護去中心化程度 —— 防止網路經濟被（惡意中心化）俘獲。

 **公民院（The Citizens’ House**） 根據"影響 = 利潤"的理念，將 `RetroPGF` 資源分配給社群專案，並幫助決定公民的身份引數。 公民院獎勵那些改善網路品質的公共產品，為這些產品提供資金。

代幣、公民兩院透過其職責、投票機制和否決權能力來保持網路的平衡。 讓我們更仔細地看一看。

![](https://app.banklessacademy.com/images/optimism-governance/introducing-the-governing-houses-bdcf1e8f.svg)

# 代幣院

代幣院維護 Optimism 網路的經濟和（技術）防禦。

職責包括：

- ⚒️ 審查和批准**網路技術升級**。
- ⛓️ 選擇網路的`區塊生產者`。
- 📈 **收入分配**，利用收取的交易費促進網路發展。

為保護網路，公民院有權`否決`上述類別下的任何提案。

代幣院還可以否決公民院或 Optimism 基金會提交的任何被認為會減少代幣持有者權利的提案。

![](https://app.banklessacademy.com/images/optimism-governance/the-token-house-7d73ce82.svg)

# 代幣院：加入、投票、授權

📝 **加入**：代幣院透過購買和持有 OP 代幣完成。 這些是 `ERC-20` 代幣，因此可以轉讓；它們可以在 中心化交易所、Optimism  去中心化交易所上買賣，也可以在朋友之間傳送。 OP 代幣不能在其他網路上使用。

🗳️ **投票**：投票權基於代幣持有數增減。

代幣院根據[5周投票週期](https://community.optimism.io/docs/governance/token-house-history/)開展投票

- 第 1-3 周：提案提交、審查和反饋。
- 第 4-5 周：投票。

📢 **委託**：許多使用者喜歡將投票權委託給他們認為最能代表社群利益的其他代幣持有者。 這是對生態系統產生影響而不必閱讀每一項表決提案的一個極好的方法。 委託不會影響代幣所有權 —— 被委託的 OP 代幣將保留在您的錢包中。

任何人都可以成為 Optimism 代幣院代表，代表一群朋友、一個社群，甚至一所大學的區塊鏈俱樂部！ 積極的代表往往會得到社群的獎勵。

# 公民院

公民院在 Optimism 上發展公共基礎設施。 它的主要重點是管理追溯性公共產品資金。

職責包括：

- 🎯 **界定 RetroPGF 指標和影響標準**用於衡量專案績效。
- 🔍 **研究並將 RetroPGF**分配給符合指導方針的社群專案。
- 👬 **挑選新公民**幫助管理公民院，平衡代幣院的觀點。 代幣院對此類提案擁有否決權。

公民院還需確保代幣院的提案是使命導向的，使用否決權機制讓非使命導向的提案失效。

![](https://app.banklessacademy.com/images/optimism-governance/the-citizens-house-aa93f52c.svg)

# 公民院：加入、投票、授權

📝 **加入**：公民院目前透過邀請的方式增加成員，慢慢擴大規模，完善程式。 "公民徽章"是一種不可轉讓的`ERC-721`通證，持有即可成為公民院的一份子。

邀請會根據 Optimism 基金會的實驗的情況每個賽季發生變化。

- 現有公民可以獲得額外的邀請，與他們認為對網路大有裨益的人分享。
- 以前的 RetroPGF 獲得者有機會選擇一名社群成員獲得公民身份。
- Optimism 基金會向使用該網路的專案建設者頒發公民證書。

隨著擴充套件方法的完善，增長將透過`鏈上治理`實現自動化。

🗳️ **投票**：每位公民只有一票。 其投票權不得轉讓或委託。 這可以防止眾議院的權力集中在少數公民手中。

目前，RetroPGF 大約每年發放兩次。

# 治理賽季

Optimism 採用**一種迭代的治理方法**，使用"季（賽季）"為日曆結構。

透過在積極治理和反思之間切換，參與者獲得了第一手經驗，隨後對當前的治理做法進行了消化和討論。 之後，Optimism 基金會將會對模型進行改進，並開始下一季的工作。

Optimism 的一個賽季大約持續三個月，之後是類似長度的反思期（reflection period ）。

在整個 Optimism 系統中建立的反饋迴路經過反覆推敲，這對在 `DAO` 社群裡構築最佳治理實踐來說非常重要。

# 現在... 還可以想得更遠！
