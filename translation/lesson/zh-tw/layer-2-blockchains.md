# 引言

任何區塊鏈的理想狀態，都是儘可能做到去中心化、安全和可擴充套件。要讓一條鏈同時做好這三件事，一直是尚未解決的難題。這個難題有個名字：`區塊鏈三難困境`。

比特幣和以太坊都相當去中心化、也足夠安全，但擴充套件性不佳：網路繁忙時，交易費高昂、排隊時間長。為了繞開這些限制，探索者可以藉助各種技術，大幅降低交易成本、提升交易速度。它們統稱為 Layer 2（L2）擴容方案。

`Lightning Network` 是比特幣最知名的擴容方案，它依靠`支付通道`技術來擴充套件支付。以太坊則透過多種 L2 方案來處理交易，緩解三難困境，背後由 2024 年加入主網的廉價臨時儲存 `Blob` 提供支援（這是當年設想的「分片」的輕量形態）。

![](https://app.banklessacademy.com/images/layer-2-blockchains/introduction-c1f2c88f.svg)

# 支付通道

在比特幣區塊鏈上，Lightning Network 依靠雙向支付通道，讓多方無需在主鏈上交易就能交換 BTC。

這套架構讓兩個使用者之間開啟一條支付通道。每條通道嚴格只有兩方，但支付可以在互聯的通道網路中路由，抵達更遠的使用者。通道開啟到關閉之間，雙方可以來回轉移資金。每位參與者的微型帳本條目在雙方都簽名後更新，這通常要求雙方的節點都線上。
任何一方都可以隨時把最新版本的微型帳本廣播到區塊鏈上，從而關閉通道。

支付通道不支援複雜的`智能合約`互動，只支援基礎的點對點交易。

![](https://app.banklessacademy.com/images/layer-2-blockchains/payment-channels-31677af9.svg)

# 以太坊的擴容方案

以太坊開發者研究原生擴容方案的時間，幾乎和這條網路上線的時間一樣長。

多數以太坊社群成員認為，要稱得上「以太坊擴容方案」，專案必須在不犧牲`安全性`和`去中心化`的前提下，解決以太坊的`可擴充套件性`短板。對使用者來說，最實際的需求是比以太坊主網更快的交易和更便宜的 `Gas`。為了競爭，有些方案願意在三難困境上做出比別人更大的取捨。

以太坊的定位由智能合約能力決定，因此擴容方案繼承這項能力同樣重要。如果使用者在 Layer 2 上用不了自己喜歡的 `dApp`，再快再便宜的交易也沒有意義。

# 連線 Layer 1 與 Layer 2

正如我們在[區塊鏈基礎](https://app.banklessacademy.com/lessons/blockchain-basics)中學到的，區塊鏈是一種叫`帳本`的資料庫，記錄著一份由密碼學保護、按時間排序的交易清單。L1 區塊鏈和 L2 擴容方案各自都是完整的區塊鏈，擁有自己的地址和資料。

在不同區塊鏈資料庫之間傳遞資訊的基礎設施，叫做`跨鏈橋`。舉個例子：把以太坊主網（或任何其他 `L1` 區塊鏈）想像成一座島，把另一條鏈或你偏好的擴容方案想像成另一座島，跨鏈橋就是連線這兩座數位島嶼的高速公路的統稱。

這項技術非常複雜，但從終端使用者的角度看，整個過程簡單到只是選一個目的地。

![](https://app.banklessacademy.com/images/layer-2-blockchains/bridging-layer-1-and-layer-2-c219a748.svg)

# 側鏈

`側鏈`是一條獨立於以太坊執行的區塊鏈，透過`跨鏈橋`與以太坊主網相連。要遷移代幣，你把它們鎖在主網的跨鏈橋合約裡，側鏈上會鑄造出等量的代幣。重要的是：這並不會讓你的資金獲得以太坊的安全性。跨鏈橋和側鏈都依賴側鏈自己的驗證者。其中任何一方被攻破（比如 2022 年 6.25 億美元的 Ronin 跨鏈橋被盜事件），鎖定的資金就可能被偷走。

側鏈同樣受制於三難困境。它們更低的 `Gas` 費和更快的交易，來自一個規模更小但更強大的驗證者集合，用一部分去中心化和安全性換來了可擴充套件性。

Polygon PoS 這類側鏈會定期向以太坊釋出快照（「檢查點」）。這讓它們的歷史獲得某種最終性，也讓使用者在退出跨鏈橋時能證明餘額，但並不能讓側鏈上的資金和主網一樣安全。

![](https://app.banklessacademy.com/images/layer-2-blockchains/sidechains-464f0191.svg)

# Rollup

使用 Rollup 技術的 Layer 2 協議，在安全級別上與以太坊主網保持更緊密的一致。

和側鏈一樣，Rollup 讓鏈上交易在以太坊主網之外執行。這些交易隨後被「捲起」成一個批次，批次資料以廉價的臨時資料包 `Blob` 的形式釋出到以太坊，Blob 由 2024 年 3 月的 Dencun 升級引入，也是典型 L2 費用降到幾美分甚至更低的主要原因。

為了證明自己足夠安全、有資格代表主網處理交易，Rollup 必須提供「令人信服的證據」，說明每個提交批次裡的交易都安全有效。這份證據包含在交易的 Rollup 中，並由以太坊主網上的跨鏈橋合約驗證。

目前有兩種 Rollup 方法能提供這種證據：`Optimistic Rollup` 和 `ZK Rollup`。我們來仔細看看這兩種流程。

![](https://app.banklessacademy.com/images/layer-2-blockchains/rollups-308dc6c9.svg)

# Optimistic Rollup

Optimism、Base、Arbitrum 這些 L2 協議，都採用 `Optimistic Rollup` 作為擴容架構。之所以叫「樂觀」，是因為 Rollup 批次裡的資訊在被證偽之前都預設有效：這是一個樂觀的假設。

為了防止有人濫用這種做法，使用者申請把資金從 L2 移回主網時，通常要等待數天。在這段時間裡，跨鏈橋的驗證者可以釋出`欺詐證明`，請求取消這筆提款。這套欺詐證明機制類似銀行業的清算流程，只不過是去中心化的。

注意：Across、Relay 這類第三方跨鏈服務，能讓使用者在幾分鐘而不是幾天內完成跨鏈。這些快速橋用自己的資金池先墊付給你，因此你要承擔該橋智能合約和資金提供方的風險，比使用 Rollup 自帶的橋多了一層信任。

![](https://app.banklessacademy.com/images/layer-2-blockchains/optimistic-rollups-846aad61.svg)

# ZK Rollup

`ZK Rollup` 是一類依靠零知識技術的 Rollup。和 `Optimistic Rollup` 不同，ZK Rollup 確認批次交易是否合法時，不依賴某些使用者去尋找欺詐的證據，而是提交一份數學證明，叫做`有效性證明`，讓以太坊無需重做計算就能檢查整個批次是否正確。

ZK Rollup 最大的優勢在於`結算時間`，也叫`交易最終性`。它不需要長達數天的挑戰期：只要下一份有效性證明提交，使用者通常在幾小時內就能在主網動用自己的資金。別被名字誤導，這裡的零知識技術並不是為了隱私：主流 ZK Rollup 上的交易和以太坊主網一樣公開。

已經有一些重要協議在用 ZK Rollup 技術構建以太坊擴容方案，包括 ZKsync、Starknet 和 Linea。這個方向仍處於早期，但未來潛力很大。

![](https://app.banklessacademy.com/images/layer-2-blockchains/zk-rollups-9d65de85.svg)

# 跨鏈 dApp 相容性

比較 `Optimistic Rollup` 和 `ZK Rollup` 時，多數使用者最關心提款時間。不過這類提款延遲可以用第三方跨鏈橋解決，所以在挑選擴容方案時，它不該是主要考量。

許多 Optimistic Rollup 做到了「EVM 等效」，也就是這條 L2 原生支援任何能在`以太坊虛擬機器`（EVM）上執行的 dApp。EVM 等效意味著此前部署在主網上的智能合約都能直接部署過來，於是 L2 使用者也能用上自己喜歡的 dApp。

Polygon PoS 這類側鏈同樣原生執行 EVM，多數現代 ZK Rollup（比如 ZKsync、Linea、Scroll）也做到了 EVM 等效或非常接近。因此，你喜歡的以太坊 dApp 在大部分 L2 生態裡都能用。

![](https://app.banklessacademy.com/images/layer-2-blockchains/cross-chain-dapp-compatibility-8a372647.svg)

# 課程回顧

比特幣、以太坊這樣的 L1 區塊鏈，目前都受制於`區塊鏈三難困境`。比特幣網路上的`支付通道`，以及以太坊上的側鏈和 Rollup，幫助這些網路擴容、緩解三難困境。

`跨鏈橋`把 L1 區塊鏈與`側鏈`和 `Rollup` 連線起來，而跨鏈橋合約的運作方式，決定了所連線網路的性質。

側鏈上的資金並不繼承以太坊的`安全性`：跨鏈代幣被鎖在主網的合約裡，但它們是否安全，取決於側鏈自己的驗證者和跨鏈橋合約。這類鏈擁有規模小但強大的驗證者集合，因而能提升交易速度、降低 Gas 費，代價是去中心化和安全性。

Rollup 和側鏈一樣也自行驗證和處理交易，但它們的跨鏈橋合約要求先提供交易有效的「令人信服的證據」，資料才被認可。這讓它們的`安全性`和`去中心化`程度與以太坊的價值觀保持一致。提供這種「證據」有兩種方法：Optimistic Rollup 和 ZK Rollup。`Optimistic Rollup` 在主網結算交易批次前會留出數天延遲，期間由跨鏈橋驗證者發現並舉報欺詐。`ZK Rollup` 則藉助`零知識`技術，為交易的合法性提供數學保證。

目前，Optimistic Rollup 和現代 ZK Rollup 都與以太坊主網有很高的智能合約相容度，主網上的 dApp 可以輕鬆部署到它們的網路上。許多人相信，憑藉快速最終性和強有力的有效性保證，ZK Rollup 會成為未來的擴容方案。
