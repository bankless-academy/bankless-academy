# DeFi 的定義

DeFi 是 decentralized finance（`去中心化`金融）的縮寫，指執行在公共`區塊鏈`網路上的一整套金融產品、協議和應用。

DeFi 是傳統金融服務之外一個成熟、開放的選擇，提供了一系列工具，讓你的加密資產動起來。它帶來的機會不止於在中心化交易所買幣，還讓任何人都能建立去中心化的 Bankless 生活方式。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-defined-759c5922.svg)

# 為什麼選擇 DeFi？

只要有網路連線，DeFi 就能讓任何人用上覆雜的金融工具：投資、交易、借貸和質押。

DeFi 以透明、開放的方式提供這些工具。任何人都可以檢視程式碼，驗證合約確實在做它宣稱的事，而銀行處理你的錢時都是關起門來的。

而且中間沒有任何機構決定誰能參與：沒人能把你拒之門外，沒人能凍結或關閉你的帳戶。

# 賺取收益

許多 `DeFi` 協議讓你把加密資產用起來，賺取利息和其他獎勵。你能用上通常要靠銀行或金融服務公司才能提供的金融產品，不必經歷傳統金融那套文書、審批和繁瑣流程。

DeFi 不是免費的：每筆交易都要付一小筆網路費用，很多協議也會收費。但這些成本通常更低、也完全透明，沒有銀行的管理開銷，也沒有機構能卡住你的使用權或收益。這正是 DeFi 受歡迎的原因。

![](https://app.banklessacademy.com/images/intro-to-defi/earning-yield-bc952747.svg)

# DeFi 能做什麼

`DeFi` 交易是`無需許可`的。這指的是任何人都能使用的公共`區塊鏈`，可以在上面買入、賣出或交易資產。沒有第三方控制或監管這些活動。這些交易由去中心化應用完成，也就是 dApp。

`dApp` 和 DeFi 平臺全天候運轉，遍佈全球。很多平臺建立在`穩定幣`之上，這類代幣的設計目標是保持穩定的美元價值（見我們的[讀懂穩定幣](https://app.banklessacademy.com/lessons/understanding-stablecoins)課程）。下面我們會介紹 DeFi 中最常見的四種活動：投資、交易、借貸和質押。

![](https://app.banklessacademy.com/images/intro-to-defi/what-you-can-do-with-defi-e1e865b5.svg)

# 投資

最常見的 `DeFi` 交易，是買入一些加密貨幣，期待它將來更值錢。這就是投資。

HODL 是長期持有加密資產的說法。至於它的來歷，有人說是 HOLD 的拼寫錯誤，也有人說它代表 **H**old **O**n for **D**ear **L**ife（拼命拿住）。

DeFi 還能讓你在新幣和新代幣登陸中心化交易所（CEX）之前，就提前接觸到它們。

![](https://app.banklessacademy.com/images/intro-to-defi/investing-7c8b44ed.svg)

# 交易

去中心化交易所（DEX）會顯示不同加密代幣和幣種之間的當前匯率，它是一個數位市場，把買家和賣家聚到一起，方便他們把一種貨幣換成另一種。

在 DEX 上交易的雙方不需要認識或信任彼此。事實上，看起來你像是在和 DEX 交易。但多數情況下，DEX 會建立`流動性池`，以`無需許可`的方式促成兩個交易者`錢包`之間的兌換。

![](https://app.banklessacademy.com/images/intro-to-defi/trading-67935721.svg)

# 所以呢？

無論淨資產多少，任何人都能參與交易和市場。任何人都能透過鏈上協議建倉或平倉。

# 借出與借入

DeFi 的借貸不需要銀行或中介機構。放貸發生在`點對點`層面：`dApp` 直接把出借人和借款人連起來。出借人賺取利息，借款人償還本金加利息。

要借款，你得先存入價值高於貸款的加密資產作為`抵押品`。如果抵押品價值跌得太多，它會被自動賣出來償還貸款。這叫`清算`，也是 DeFi 貸款不做信用審查卻能保持安全的方式。

![](https://app.banklessacademy.com/images/intro-to-defi/lending-borrowing-b7d58dfa.svg)

# 質押

`質押`常和借貸放在一起講，但兩者不同：質押沒有借款人。你鎖定自己的`以太幣`來幫助保護以太坊網路，網路則以獎勵回報你。

質押的資金可能會被鎖定一段時間，行為不端的`驗證者`會失去一部分質押，所以誠實才划算。中心化交易所也提供質押，但 DeFi 給你更多選擇，同時讓你保持對資產的控制權。想了解更多，請看我們的[在以太坊上質押](https://app.banklessacademy.com/lessons/staking-on-ethereum)課程。

# DeFi 的缺點

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-da1fdb68.svg)

**駭客**

哪裡有錢和技術，哪裡就有人想辦法攻破系統。DeFi 協議和它們的使用者經常成為目標，所以安全習慣很重要。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-d533aeef.svg)

**風險**

DeFi 執行在程式碼上，也就是`智能合約`。程式碼裡的錯誤或漏洞可能被利用來掏空資金。市場也帶來風險：價格下跌時貸款會被清算，`穩定幣`也可能失去穩定的價值。

![](https://app.banklessacademy.com/images/intro-to-defi/defi-downsides-0070f0e1.svg)

**無處申訴**

這裡沒有客服電話，出了問題也沒有公司或政府機構可以申訴。丟失或被盜的資金通常無法撤銷或賠付。
