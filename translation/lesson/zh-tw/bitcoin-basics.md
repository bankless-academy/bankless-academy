# 貨幣簡史

從最早的時代起，貨幣就是社會的重要組成部分：人們用珠子、貝殼和石頭交換商品與服務。

但早期貨幣有個問題：新的貨幣太容易被找到或造出來。一樣東西越多，價值就越低，於是每個人手裡的錢會慢慢變得不值錢。貨幣要守住價值，就必須更難獲得。

後來人們採用黃金和白銀來解決這個問題。它們的關鍵優勢在於稀缺：供應不是無限的，誰都很難大幅增加流通中的貨幣量。這種`稀缺性`幫助貨幣保住了價值。

隨著社會發展，政府的中央銀行開始發行標準化的金銀鑄幣。這樣的貨幣既好辨認又好計量，也是可靠的價值儲存手段。

# 貨幣簡史（第二部分）

紙幣出現後，各國貨幣改由黃金「背書」。貨幣的價值直接對應倉庫裡存放的一定數量的貴金屬。

到了 20 世紀，這套「`金本位`」倒下了。

貴金屬逐步與世界各國的貨幣脫鉤，好讓一國經濟能突破本國黃金儲備的限制繼續增長。中央銀行不再需要黃金就能創造貨幣，可以按本國經濟的需要發行任意數量的新錢。牢牢掌握貨幣供應量，也就掌握了貨幣的價值。

進入數位時代，電子貨幣已大量取代實體貨幣。把錢存在商業銀行裡，讓我們用上了信用卡和支付軟體。這既方便又安全，但也把營利性企業塞進了我們和自己的錢之間。

![](https://app.banklessacademy.com/images/bitcoin-basics/a-brief-history-of-money-part-2-3f9be5ac.svg)

# 問題所在

當今金融體系的問題在於：我們對自己的錢缺乏控制權，這削弱了我們自由決定存多少、花多少的能力。

`中央銀行`管理著一國的`貨幣政策`，可以隨意投放新的貨幣。缺少`稀缺性`，往往讓我們的錢一年比一年不值錢。價值不可預測、不斷下滑的貨幣，會逼著我們把它花掉：**「反正我的錢每年都在貶值，為什麼還要存？不如現在就花了。」** 💸

`商業銀行`是我們日常存錢和花錢的地方，它同樣影響著我們的消費習慣。作為`託管方`，它可以攔下交易，也可以扣押我們的資金。有些銀行甚至禁止客戶購買加密貨幣！**如果銀行隨時能凍結你一輩子的積蓄……你真的擁有自己的錢嗎？** 💸

---

貨幣要重新支撐財務自由，就必須找回兩個逐漸失去的關鍵屬性：

- 💎 **價值：** 貨幣必須能長期可靠地儲存價值。
- ✊ **所有權：** 貨幣必須便於我們自己保管和保護。

只有具備這些特質，我們才能重新自由地儲蓄和消費。

# 比特幣登場

`中本聰`認為，貨幣太重要了，不該由少數人控制。他們想創造一種對所有人都公平、可靠的貨幣。

比特幣（`BTC`）由此誕生：一種執行在傳統銀行體系之外的數位貨幣。

- ⛓️ 它是`點對點`的：直接把人和人連起來。靠`區塊鏈技術`自動執行，不需要機構代為保管或處理交易。支持者稱它是「一套沒有統治者的規則」。
- 💎 它是`稀缺`的：沒有中央銀行無限增發，比特幣的貨幣政策穩定可預測，尊重長期儲蓄。
- ✊ 它是`自我託管`的：不需要機構託管轉帳或資產。網路記錄誰擁有什麼，你的`私鑰`來證明：只有持鑰人才能動這些幣。

憑藉這些特質，比特幣贏得了「數位黃金」的稱號。

![](https://app.banklessacademy.com/images/bitcoin-basics/enter-bitcoin-b108517c.svg)

# 數位黃金：稀缺性

📉 你是否覺得越來越難跟上上漲的物價？

比特幣的稀缺性指的是它有數量上限：最多隻會有 2100 萬枚。這個`最大供應量`寫在程式碼裡，讓比特幣像黃金一樣稀有。

新幣仍會透過一個費力的過程進入`流通供應量`，這個過程叫`加密貨幣挖礦`。大約每四年，新幣的發行量就會`減半`，隨著接近上限逐漸趨向於零，因此礦工會越來越依賴交易手續費。

比特幣固定的`貨幣政策`讓它適合長期保值。自 2024 年起，受監管的基金（`現貨 ETF`）讓傳統投資者也能持有比特幣，強化了它「數位黃金」的角色。

由於市場投機，它的短期價值依然波動劇烈。

在民主社會裡，所有權是受保護的基本人權，因為它讓公民對自己的生活擁有更多控制和自由。當生存的手段要看企業或機構的臉色，我們就無法自由行動。

隨著資產越來越數位化（你的錢、你的財產，甚至你的身份），我們的生活也帶上了數位屬性，必須學會保護它。

比特幣的`自我託管`帶來真正的數位所有權，`託管方`無法觸及。你的幣不存在某個應用或網站裡：網路記錄著你的所有權，你的`私鑰`來證明它。把私鑰留給自己，你就是這座數位黃金金庫的唯一持鑰人。

這套所有權體系讓你完全掌控自己的數位財富：隨時隨地，全球通行。

# 比特幣網路

我們換個角度，看看比特幣背後的引擎：
**比特幣網路**。

比特幣執行在一個共享網路上，由全球成千上萬臺計算機共同承載。網路中的每一臺計算機都參與維持它的運轉，網路正是由這些計算機構成的！如果某一臺處理了一筆欺詐交易，其他計算機會糾正它。

這也意味著駭客攻擊時沒有單一的施壓點。要控制這個網路，就得攻陷其中的大多數計算機。

這種防禦策略叫`去中心化`：把控制權從一箇中心團體轉移到許多小團體手中。正是它讓加密貨幣網路幾乎無法被叫停。

![](https://app.banklessacademy.com/images/bitcoin-basics/the-bitcoin-network-eda52e60.svg)

# 比特幣挖礦

比特幣網路沒有中央銀行，只能依靠`去中心化`的參與者。這些參與者被稱為`礦工`，他們不斷檢查交易，並把交易寫進一個「資料庫」：`區塊鏈`。

礦工必須有動力保持活躍和誠實，才能保護網路不受欺詐。他們會頻繁複核彼此的結果，同時也因為付出的工作而獲得回報。我們提交比特幣交易時，會付一小筆手續費給打包這筆交易的礦工。礦工還會賺到新的比特幣，也就是「區塊獎勵」。

這些獎勵讓比特幣的`流通供應量`在 2100 萬 `BTC` 的`最大供應量`上限內緩慢增加。

正是這種緩慢、可預測的新幣投放，把比特幣和傳統貨幣區分開來。一切都由社群認可的計算機程式碼（「沒有統治者的規則」）和去中心化的參與者管理，而不是`中央銀行`裡的一小群人。

![](https://app.banklessacademy.com/images/bitcoin-basics/bitcoin-mining-9b8a77ea.svg)

# 傳送一筆比特幣交易

要弄懂驅動比特幣交易和挖礦的確切機制，會相當複雜。不過，使用和傳送比特幣其實很簡單！

今天我們只看一個簡化的流程：

1. 你用自己的`加密貨幣錢包`提交一筆交易，向朋友的錢包地址傳送 0.1 `BTC`。
2. 一位礦工檢查你的交易有沒有錯誤，其他礦工再複核結果。
3. 通過後，你的交易被寫入`區塊鏈`「資料庫」。
4. 你的朋友在錢包裡收到 0.1 BTC。

# 貨幣的革新

- ⚖️ 把`機會平等`寫進貨幣體系。
- 🌐 為數位時代建立真正的所有權。

新的貨幣時代正在弘揚民主的根本價值，提升全球公民的日常生活品質。而你，也在受邀之列。
