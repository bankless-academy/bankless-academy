# 錢包的定義

加密錢包到底是什麼？

簡短的定義是：它是`區塊鏈`上的一個帳戶，用來存放數位資產、登入區塊鏈應用。

它就像你在網際網路上的私人保險箱，而唯一的鑰匙在你手裡。同時，這個保險箱也很像普通的網站帳戶：你可以用它購物、收發`加密貨幣`，以及與區塊鏈互動。

但和你熟悉的 `Web2` 帳戶不同，一個錢包就能存取整條區塊鏈，以及大量區塊鏈應用。這相當於用一個帳戶走遍整個網際網路。

![](https://app.banklessacademy.com/images/wallet-basics/wallet-definition-d2912914.svg)

如果你會在電腦上下載安裝軟體（或在手機上裝應用），那麼建立第一個錢包對你來說不成問題。

挑選`錢包應用`可能也讓人有點犯難。它就是你裝在裝置上、用來存取區塊鏈錢包的那個應用。我們建議從 Zerion 錢包應用開始：它對新手友好，支援很多主流區塊鏈。等你在 `Web3` 裡更自在之後，多半還會嘗試其他服務商，建立多個錢包。

# 錢包與密碼找回

關於 `Web3` 錢包，有一點最需要理解：
**這裡沒有「重置密碼」，也沒有「修改密碼」**。

我們大多數人都習慣了這些功能。忘了密碼，點幾下按鈕，就能換一個新的。很簡單。

加密錢包不是這樣。由於區塊鏈的運作方式，錢包在建立時會被分配一個「地址」和一串複雜的「密碼」，這兩樣都不是你自己選的。

這組地址和密碼無法更改，不過你隨時可以建立新錢包。有些較新的錢包提供了找回功能，但永遠不要依賴它。下面我們就來了解這些特殊的地址和密碼，好讓你用得放心！

# 錢包的公鑰

錢包的`地址`由它的`公鑰`生成。你可以把地址當成使用者名稱：它通常看起來像一串隨機的字母和數字。

例如：_0xe1887fF140BfA9D3b45D0B2077b7471124acD242_

藉助一些 `Web3` 服務，你可以給它起一個更好記的名字，不過那是另一課的內容了。

你也可以把地址想成住址。它是公開的，誰都能看到，它告訴別人可以把加密資產發到哪裡，同時不會洩露你的任何個人資訊。

分享錢包**地址**是完全安全的。

**注意**：一個錢包應用可以儲存多組公鑰和`私鑰`。

![](https://app.banklessacademy.com/images/wallet-basics/your-wallets-public-key-87828c3e.svg)

# 錢包的私鑰

如果地址像住址，那麼`私鑰`就像大門鑰匙。它是你資金和資產的「密碼」。

例如：_eceac283e04f121cbd40b69e16ab9dec0220df80bf092a4c72b53e69cf74d215_

**分享這把鑰匙永遠不安全：你可能因此失去錢包和裡面的一切。**

多數人建議你連數位副本都不要儲存。誰拿到私鑰，誰就拿到了`錢包`裡的一切。

它不只是一個密碼。一旦失去它，你無法重置。

好在大多數`區塊鏈應用`不會要求你每次轉帳或簽署區塊鏈交易時都輸入這一長串字元。私鑰通常在後臺悄悄工作。

![](https://app.banklessacademy.com/images/wallet-basics/your-wallets-private-key-0d84ad39.svg)

# 助記詞

設定新錢包時，錢包應用會給你一組`助記詞`。

它也叫「種子短語」或「秘密短語」。在下面這些情況下，這串詞可以幫你重新存取錢包和加密資產：

- 你的`錢包應用`或裝置突然故障或損壞。
- 裝置丟失或被盜。
- 你想在多臺裝置上存取同一個錢包。

大多數助記詞由 12 到 24 個單片語成，代表一段獨一無二的資料。這段資料用來生成錢包的`公鑰`和`私鑰`。

錢包恢復**不會**更改或重置金鑰。

助記詞就像一把主鑰匙：它能重新生成錢包裡的每一組金鑰對。**永遠不要分享你的助記詞。**

![](https://app.banklessacademy.com/images/wallet-basics/recovery-phrase-c614c36c.svg)

# 錢包的型別

就像電腦軟體有很多種，錢包也有很多種。我們來看四大類：

- 🏦 **託管錢包**：由第三方負責保管你的私鑰。
- 👤 **自我託管（非託管）錢包**：由你自己負責保管私鑰。

`自我託管錢包`又分成兩種風格：

- 🔥 **熱錢包**：執行在電腦或手機上的軟體。
- 🧊 **冷錢包**：一個硬體裝置（類似 U 盤），你把它放在安全的地方。

你可能還會聽說`智能錢包`：一種新興型別，它能執行程式碼，從而支援通行金鑰登入、帳戶找回等附加功能。

每種錢包適合不同的場景。別擔心，今天我們只建立一個錢包。

![](https://app.banklessacademy.com/images/wallet-basics/types-of-wallet-094f0eb1.png)

# 託管錢包

`私鑰`是開啟你`錢包`的鑰匙，所以保管好它非常重要！

提供`託管錢包`服務的包括 Coinbase、Kraken 這類加密貨幣交易所。**它們是你的錢包託管方**：替你保管私鑰。你像使用普通網站一樣使用它們的服務（郵箱登入，密碼可重置）。

對有些人來說這就夠用了，但這要求你信任這些第三方：相信它們能保護好你的加密資產，並在你想交易或轉出時給你放行。此外，你能存取的`區塊鏈應用`可能也會受限。

![](https://app.banklessacademy.com/images/wallet-basics/custodial-wallets-4eede755.svg)

# 非託管錢包

`自我託管錢包`（例如 Zerion 或 Trezor）意味著你完全掌控自己的`私鑰`。這裡**沒有託管方**，保管私鑰的責任全在你一個人身上。

在 `Web3` 世界裡，這類錢包提供最廣的存取範圍和最大的自由。你不必擔心第三方凍結或錯誤處理你的資金。

代價是風險：如果你弄丟了`助記詞`，或者私鑰被洩露，往往幾乎沒有辦法再恢復對錢包的存取。

不管你選哪條路，熟悉並習慣錢包安全都很值得。在這一課結束之前，我們會給你一些建議。

# 熱錢包

在 `Web3` 裡，你會經常聽到「熱錢包」和「冷錢包」這兩個詞。

`熱錢包`是透過裝置上的應用存取的錢包，比如 Zerion 應用。和很多 `Web2` 應用一樣，錢包應用始終連著網際網路。

你的`私鑰`被加密後儲存在錢包應用裡，只有在你與區塊鏈互動時才會被呼叫。正是因為網際網路和私鑰之間這種「熱」連線，它們才被叫作熱錢包。

熱錢包適合日常的小額操作，就像你放在口袋裡的實體錢包。今天我們要建立的就是熱錢包！

![](https://app.banklessacademy.com/images/wallet-basics/hot-wallets-9356886d.svg)

# 冷錢包

隨著你在 `Web3` 之路上走得更遠，你會看到一個充滿有趣技術取捨的世界。

`冷錢包`用便利性換來更高的安全性。冷錢包把你的`私鑰`儲存在專用硬體裝置上（比如 U 盤或行動硬碟）。你必須把硬體錢包實際連線到電腦，才能存取區塊鏈上的錢包。私鑰從不直接連線網際網路，冷錢包的名字正來自這種「冷」連線。

人們普遍認為冷錢包比`熱錢包`更安全，因為`私鑰`離線儲存，數位攻擊者夠不著。

Ledger 和 Trezor 就是`冷錢包`的例子。

![](https://app.banklessacademy.com/images/wallet-basics/cold-wallets-0e3183d1.svg)

# 錢包安全

無論你的`自我託管錢包`是熱錢包還是冷錢包，都應該養成一些聰明的安全習慣。

🖊️ 把`助記詞`記錄在耐久的實體材料上（覆膜紙，甚至鋼板），存放在非常安全的地方。永遠不要把它或你的`私鑰`告訴任何人。**它不只是一個密碼。**

🔍 每次轉帳或簽名都要仔細核對細節，哪怕金額很小：操作無法撤銷。

🔭 在連線錢包或簽署交易之前，先研究你打算使用的`區塊鏈應用`。

💰 用只放少量資金的錢包去嘗試新事物、探索 Web3，並考慮把高價值資產分散在多個錢包帳戶裡。
