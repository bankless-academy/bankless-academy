# 引言

當想使用某條`區塊鏈`網路的使用者超出它的承載能力時，問題就來了。對`區塊空間`的大量需求可能只是一陣子，也可能只要使用者仍然強烈想用這條鏈就一直存在。需求高企時，使用者會相互抬價，讓自己的交易更快被處理，費用隨之上漲，資金較少的使用者被擠出局。

這一課會講清楚：為什麼以太坊和其他區塊鏈都受制於`區塊鏈三難困境`，這個困境如何導致上面這些問題，以及它如何影響以太坊服務全體使用者的計劃。我們還會看看幾條區塊鏈在三難困境面前做出的取捨，以及這些取捨對 Academy 探索者意味著什麼。

![](https://app.banklessacademy.com/images/layer-1-blockchains/introduction-feee7790.svg)

# 區塊鏈三難困境

正如「三難」這個詞所暗示的，區塊鏈有三種彼此競爭的特性，無法同時把三者都做到最好。

它們是：`安全性`、`可擴充套件性`和`去中心化`。

一條區塊鏈若要成為全球規模貨幣體系的中立基礎，這三方面都得出色。貨幣體系需要安全，不受欺詐侵害；需要去中心化，不被審查者攻擊；還需要可擴充套件，才能滿足全球社會 80 多億人的需求。

![](https://app.banklessacademy.com/images/layer-1-blockchains/blockchain-trilemma-9bd1b1e4.svg)

# 安全與共識

安全性是公共區塊鏈最基礎的要求。網路（比如區塊鏈網路）中的計算機必須就「究竟發生過哪些交易」達成一致，才能協同工作，這種一致就叫`共識`。如果攻擊者無法破壞網路對這個事實的一致意見，這條區塊鏈就是安全的。共識演算法正是為抵禦這類攻擊而設計的。

像比特幣這樣使用`工作量證明`共識的鏈，透過讓區塊生產變得高度競爭來保護這種一致：每個區塊生產者都搶著解一道數學題。最先解出的人贏得建立下一個區塊的權利，以及隨之而來的`區塊獎勵`。要改寫鏈上近期的歷史，需要在算力和能源上投入巨資，攻擊者花掉的多半會超過所得。

![](https://app.banklessacademy.com/images/layer-1-blockchains/security-and-consensus-4e857c50.svg)

# 安全與攻擊

對區塊鏈共識的一種可能攻擊是`51% 攻擊`：攻擊者掌握了網路中大多數共識力量，就能回滾近期交易、把同一筆幣花兩次，或者審查新交易。他們無法偽造簽名，也無法花別人的錢。這裡的「多數」，在工作量證明裡指 51% 的算力，在權益證明裡指 51% 的`質押`，都是極其龐大的資本投入。而在權益證明中，可被證明的作弊行為（比如為兩個相互衝突的區塊簽名）會導致質押被銷燬，這叫`罰沒`，攻擊者的損失多半超過所得。

在`權益證明`共識裡，區塊生產者不是透過競爭選出，而是隨機指定的。和工作量證明一樣，共識演算法確保任何單一實體都無法經常「贏得」建立新`區塊`的權利。

![](https://app.banklessacademy.com/images/layer-1-blockchains/security-and-attacks-a73febc0.svg)

# 可擴充套件性：吞吐量

`可擴充套件性`指的是一條區塊鏈快速處理大量交易的能力。它由兩部分決定：吞吐量和最終性。

1）`交易吞吐量`：區塊鏈一次能處理多少交易，通常用每秒交易數（`TPS`）來衡量。

想像很多人在公交站等車，每分鐘還有人不斷到來，大家都想出行。但一輛車能坐的人是有限的。想讓站臺更快清空，要麼換更大的車（裝更多人），要麼讓車來得更勤（間隔更短）。往每個區塊有限的`區塊空間`裡塞進大量交易，道理是一樣的。你可以在 [https://txstreet.com/v/eth-btc](https://txstreet.com/v/eth-btc) 看到帶即時資料的視覺化。

# 可擴充套件性：最終性

區塊鏈可擴充套件性的第二個方面是：

2）`最終性`：我們什麼時候可以比較有把握地認為一筆交易不會被更改或回滾？

在比特幣這樣的工作量證明鏈上，最終性以區塊數衡量：你的交易之後追加的區塊越多，你就越能確信它不會被回滾。別忘了，安全的共識演算法讓修改過去的區塊變得非常昂貴，而且越往前改代價越高。比特幣大約每 10 分鐘產出一個新`區塊`，所以等待若干次確認大約需要一小時。以太坊的權益證明走了另一條路：`驗證者`投票敲定區塊，大約 13 分鐘（兩個`時段`的投票）之後，一筆交易就是最終的了。

# 去中心化分散權力

`去中心化`是區塊鏈三難困境的最後一根支柱：把控制權和決策權從單一實體轉移到由許多參與者組成的分散式網路。正是去中心化這一根本原則，讓區塊鏈得以`無需許可`和`抗審查`：任何人都能使用去中心化區塊鏈，任何人都能基於它們開發軟體。

像 Facebook 和 Twitter 這樣的中心化平臺，可以隨時停用任何人的帳號。Twitch 或 TikTok 上不少有影響力的主播都曾無故被平臺下架。即便社交媒體使用者能把帳號恢復過來，過程也可能漫長而痛苦。沒有去中心化，區塊鏈`帳本`不過是銀行電腦裡的一張財務表格，由銀行家決定誰可以開戶。`無需許可`的網路意味著權力足夠分散，沒有任何辦法能剝奪某個人或實體的存取權。

![](https://app.banklessacademy.com/images/layer-1-blockchains/decentralization-distributes-power-feafb05a.svg)

# 它去中心化嗎？

不過，某樣東西是否去中心化，並不是簡單的是或否。10 個控制實體算去中心化嗎？1000 個呢？100 萬個呢？「足夠去中心化」並沒有統一的標準線，所以把去中心化看成一個光譜更合理。除了非黑即白，中間還有許多灰度。

於是我們可以說某樣東西「比另一樣更去中心化或更不去中心化」，而不是簡單地說「中心化還是去中心化」。要讓一箇中立的貨幣體系抵禦國家層面的審查，就需要很高的去中心化程度。較新的區塊鏈常常用去中心化換取可擴充套件性，但這也讓它們暴露在社會和政府的同樣壓力之下，就像完全中心化的平臺那樣。它們最終可能做出與中心化社交網路一樣的審查行為。

# 一些例子

每條區塊鏈都有自己應對三難困境的方式，也都為聚焦自身目標做了取捨。比特幣和以太坊把安全性和去中心化排在可擴充套件性之前，代價是比特幣的`最終確定時間`很長，以太坊的`區塊空間`很有限。當使用`智能合約`的需求激增，尤其是 DeFi 相關需求時，以太坊的費用就會上漲；在 2021 年的需求高峰，一筆交易可能要花幾十美元。

費用上漲給 BNB Chain 這類`替代性 Layer 1` 留出了空間，它們用去中心化換取可擴充套件性，以獲得更高的`交易吞吐量`和更低的費用。Solana 這樣的第三代鏈用新方法來解三難困境，但所有區塊鏈仍然受制於這些基本約束。每條鏈的選擇，都會透過隨之而來的基礎性影響塑造出它自己的生態。

![](https://app.banklessacademy.com/images/layer-1-blockchains/some-examples-30020a8d.svg)

# 那能做些什麼？

既然以太坊把高安全性和高去中心化放在首位，它又該如何擴充套件，成為它想成為的全球金融網路、服務所有使用者？以太坊路線圖探索過兩個答案：`Layer 2` 和區塊鏈`分片`。

`Layer 2` 能在不犧牲三難困境另外兩項的前提下提升以太坊的可擴充套件性。它們是架在主鏈之上的額外一層，安全性依賴主鏈，同時讓使用者享受更低的費用和更快的交易。我們會在 Layer 2 課程裡詳細介紹。

`分片`本來會把區塊鏈拆成多條並行的鏈，就像給道路增加車道。以太坊把這個方案放到了一邊，選了更簡單的一條路：讓區塊資料對 Layer 2 來說更便宜（2024 年上線），並一步步提升容量，同時不犧牲安全性和去中心化。

![](https://app.banklessacademy.com/images/layer-1-blockchains/so-what-can-be-done-043c43fb.svg)

# 以太坊的未來

以太坊網路在不犧牲三難困境其他方面的前提下，持續提升可擴充套件性。轉向`權益證明`共識的合併（2022 年）把網路能耗降低了 99% 以上，面向 Layer 2 的廉價區塊資料則在 2024 年到來。**擴容是一項持續的工作：每一次升級都讓以太坊更快、更便宜，同時把安全性和去中心化作為核心信條保留下來**。以太坊基金會有一個很棒的[以太坊路線圖](https://ethereum.org/roadmap/)頁面。

與此同時，許多 `Layer 2` 協議在以太坊之上構建，幫助滿足使用者需求，而不需要改動以太坊協議本身。這些 Layer 2 協議依靠 Layer 1 以太坊提供去中心化的安全性，自己則提供可擴充套件性；Layer 2 的多樣性造就了一個去中心化的生態！主要的 `Rollup` 包括 Arbitrum、OP Mainnet 和 Base；Polygon PoS 是一條流行的`側鏈`，有自己獨立的安全性。

# 這對探索者意味著什麼？

使用者需要低費用，才能以較低的門檻和較小的試錯成本去學習和探索這項技術，剛起步時尤其如此。以太坊區塊鏈還不夠理想，但它的價值觀讓它成為實現「全球金融計算系統」這一夢想的最佳候選之一。探索者可以在不支付高額費用的情況下學著與以太坊互動；使用 Layer 2，探索者既能獲得以太坊的安全性和去中心化優勢，又能享受更高的可擴充套件性。
