# 在以太坊上質押

歡迎你，探索者，來到新的一課！

今天我們來看看「質押」：一種積累數位財富的簡單方式。

`質押`和比特幣網路上的`挖礦`很相似：兩者都是讓參與者處理區塊鏈上的交易、換取獎勵的機制，也都讓我們的網路保持`去中心化`。

不過挖礦和質押有個重要區別。在以太坊上質押，不需要用強大的電腦去和別人競爭。只要把以太幣（ETH）鎖進網路的`智能合約`，就能讓以太坊運轉下去，並獲得獎勵。

![](https://app.banklessacademy.com/images/staking-on-ethereum/staking-on-ethereum-50472cf7.png)

# 以太坊需要你！

把`質押`想像成一種「網際網路債券」。

就像買政府債券支援國家能帶來財務回報一樣，支援以太坊也有獎勵！更棒的是，和政府債券一樣，質押也是一種用財務行動表達價值觀、支援你想要的世界的方式。

當你質押以太幣時，它會被分配給一個正在處理以太坊交易的`驗證者節點`。質押的以太幣越多，以太坊能擁有的節點就越多。節點越多，以太坊就越`去中心化`、越安全。

作為一名`質押者`，你成為了**以太坊的守護者！**

現在，我們來深入瞭解質押的運作機制，找到一個輕鬆、低成本的方式，今天就開啟你的質押之旅。

帶上裝備，出發吧！

![](https://app.banklessacademy.com/images/staking-on-ethereum/ethereum-wants-you-fd40b9e5.png)

# 區塊鏈安全

`驗證者節點`是以太坊經濟安全、可信的關鍵。它們保護區塊鏈免受`欺詐`。

區塊鏈世界裡的欺詐，是指使用者篡改餘額或憑空造出不存在的加密資產。以太坊遏制它的辦法，是確保每一筆交易都有效，且沒有任何參與者能凌駕於他人之上。這種公平叫做`可信中立`，至關重要。為什麼？沒人願意待在一個充滿欺騙和不信任的經濟體裡，它最終會崩塌。

在一條健康的區塊鏈上，驗證者節點有共同的目標：**在全網範圍內，就區塊鏈的狀態達成去中心化的一致。** 節點會掃描交易，對照區塊鏈的歷史核對，並對其有效性投票。透過節點`共識`、被認定有效的交易，才會被寫入區塊鏈。

![](https://app.banklessacademy.com/images/staking-on-ethereum/blockchain-security-7f2149fe.svg)

# 權益證明

想執行`驗證者節點`的使用者必須鎖定至少 32 ETH，這是一筆不小的錢。（自 2025 年起，單個驗證者也可以持有更高的餘額，質押者隨時可以透過排隊退出。）作為在網路中投入大額「權益」的回報，`節點運營者`可以在以太坊上提議和稽核交易區塊，並賺取獎勵。你可以把區塊理解成提交給網路的一組交易。

網路的`共識機制`會隨機選出一個驗證者節點來提議下一個區塊，它的決定會由其他節點複核，以確保誠實。當一個節點成功提議一個區塊，它的`質押`就會增長。

![](https://app.banklessacademy.com/images/staking-on-ethereum/proof-of-stake-49c358ed.svg)

# 罰沒

當一個節點被證實作弊，比如簽署兩個相互衝突的區塊，它的質押就會`被罰沒`：損失一部分以太幣。反應慢或者掉線不算`罰沒`，那隻會帶來一點小懲罰。這樣一來，質押的以太幣就成了保證金，激勵節點保持誠實、讓以太坊平穩執行。

攻擊者若想在以太坊上讓欺詐通過，必須控制多數驗證者節點，也就是多數質押的以太幣。好在只要普通使用者參與質押，這種情況就不會發生。網路所有權的`去中心化`，把決策權分散開來。

# 驗證交易

我們來一步步看看，節點如何用`權益證明`共識達成一致：

1. **質押：** `節點運營者`在網路上鎖定 32 ETH，開始執行`驗證者節點`。
2. **區塊構建：** 使用者提交交易，由`區塊構建者`把它們整理成`區塊`。
3. **提案者選擇：** 演算法選出一個驗證者節點，來提議下一個要加入區塊鏈的區塊。
4. **區塊提議：** `區塊提案者`稽核候選區塊並選出一個，若有效就給予`證明`。
5. **交叉驗證：** 其他驗證者複核該區塊，若有效同樣給予證明。無效區塊會被直接忽略，永遠不會進入鏈上。
6. **區塊寫入：** 有效的區塊被加入以太坊區塊鏈。
7. **獎勵：** 區塊提案者獲得`區塊獎勵`和交易小費。其他驗證者也會獲得獎勵。

# 以太經濟學

質押者把以太幣提供給驗證者節點，就能分到它的一部分獎勵。

節點獲得的獎勵取決於多種生態因素，也會變化。簡單說，獎勵來自交易費的一部分，加上寫入新區塊的少量新發行以太幣。

年化收益會隨時間變化，歷史上大致是質押以太幣的百分之幾。具體數額由兩個關鍵因素決定：

- 📈 **網路活躍度：** 一般來說，網路流量低，獎勵就低；流量高，獎勵就高。
- 👥 **驗證者節點數量：** 參與者越多，獎勵分得越細。

收益也取決於你具體用哪種方式質押以太幣。我們來看看有哪些選擇。

# 質押的方式

執行`驗證者節點`通常需要鎖定 32 ETH，但新的質押方式讓守護以太坊變得人人可及。

所以，保護以太坊有三種方式：

- 📡 **單獨質押：** 自己執行一個驗證者節點。
- ⛲ **質押池：** 加入一群質押者，一起執行節點。
- 🏦 **中心化交易所質押：** 加入「加密銀行」的節點。

每種方式在設定時需要的技術知識各不相同，也各有各的風險。

如果你願意自己保管`私鑰`，但沒有 32 ETH，那可以考慮和別人一起加入質押池。

如果你還不習慣`自我託管`自己的加密資產，可以看看中心化交易所質押。同時，去上我們的[錢包基礎](https://app.banklessacademy.com/lessons/wallet-basics)課程，勇敢地掌握自己的加密資產！

# 網路中心化

**任何讓大量節點集中到同一個實體手裡的質押方式，都會讓以太坊走向中心化。**

把以太坊想像成一張由`驗證者節點`連成的網。當節點集中在一個或少數幾個實體手裡，整張網就會失衡、不再安全。為了避免這種情況，我們需要大量彼此獨立的連線點。

單一實體掌控足夠多的節點是件壞事。這會迫使交易區塊從網中被中心化的那一段通過。這個中心化實體可能開始批准欺詐區塊，甚至拒絕有效的區塊，從而摧毀以太坊的`可信中立`。

作為守護者，我們必須關注那些讓這張網保持均衡和`去中心化`的質押方式。

作為新手，自己執行驗證者節點會遇到不少門檻。我們不如來看看一個對新手友好的去中心化質押選擇：`質押池`。

# 質押池

`質押池`最大的好處，是它完全由`智能合約`執行。你不必和其他質押者見面，也不必信任他們。但你確實需要信任那份智能合約。

質押池由`質押服務商`組織，這些數位平臺把全世界的質押者連線起來！在質押池裡，一位`節點運營者`拿出 32 ETH 中的一部分並執行節點，其餘以太幣由其他參與者提供。節點運營者因為提供這項服務而獲得額外收益。

其餘質押參與者會拿到「流動性質押代幣」（LST），代表他們在池中的成員份額。這些`代幣`代表池中質押以太幣的一部分，持有者按所代表的份額分得獎勵，並可以隨時用它贖回自己的質押。

只要持有一枚 LST（比如 Rocket Pool 的 rETH），你就擁有一個質押池的份額。沒錯，你的以太幣正在讓以太坊更去中心化，同時賺取質押獎勵！

![](https://app.banklessacademy.com/images/staking-on-ethereum/staking-pools-46c96251.svg)

# 流動性質押代幣

`LST` 最大的好處在於：即使你的以太幣已經質押並在賺取收益，它依然保持`流動性強`的形態。

這裡的「流動」是指它仍然可以在整個生態中流轉。想像一下你手裡握著質押池的份額……而它還能當錢用！LST 可以拿去兌換、當作貸款的抵押品，甚至存進`再質押`平臺，那是一種可選策略，用額外的風險換取額外的收益。

LST 很棒，因為它打開了通往質押以太幣的大門。質押池往往對入池金額設有下限（大約 0.01 ETH）。但透過 LST，你可以在自己喜歡的`去中心化交易所`上買到更小份額的質押以太幣。

# 又是網路中心化！

質押池和 LST 也有和各種質押方式一樣的問題：**它們的中心化與去中心化程度各不相同。**

像 Rocket Pool 這樣的`質押服務商`已經做到，讓任何地方的任何人都能成為質押池的`節點運營者`。這幫助新的節點運營者攢夠 32 ETH 的質押，也讓以太坊更去中心化。但也有服務商只允許一小圈熟人來執行節點，這就帶來了質押以太幣中心化的風險。

如果某個實體控制了全部質押以太幣的 33% 以上，就可能給網路製造麻煩。到了 50%，它會嚴重威脅以太坊的`可信中立`。

一些大型質押服務商已經接近過 33% 這條線。把質押分散到多個服務商，才能讓網路保持安全。

要守護以太坊，我們需要做功課。即使用`質押池`，我們也要做出支援去中心化的選擇。
