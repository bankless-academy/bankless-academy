# Staking sa Ethereum

Welcome, Explorer, sa susunod mong lesson!

Ngayon, titingnan natin ang proseso ng "staking": isang simpleng paraan para bumuo ng digital wealth.

Ang `staking` ay katulad ng `mining` sa Bitcoin network: parehong sistema ito para hayaang i-process ng mga participant ang mga transaksyon sa blockchain kapalit ng rewards. Pinapanatili nila ang `decentralized` ang mga network natin.

Pero may isang mahalagang pagkakaiba ang mining at staking. Ang staking sa Ethereum ay hindi nangangailangan ng malakas na computer para makipagkumpitensya sa iba. Ang pag-lock lang ng Ether (ETH) sa isang network `smart contract` ang nagpapatakbo sa Ethereum at nagbibigay sa iyo ng rewards.

![](https://app.banklessacademy.com/images/staking-on-ethereum/staking-on-ethereum-50472cf7.png)

# Kailangan Ka ng Ethereum!

Isipin ang `staking` bilang isang "internet bond".

Kung paano nagbibigay ng financial returns ang pagsuporta sa gobyerno mo sa pamamagitan ng bonds, ganoon din nagdudulot ng rewards ang pagsuporta sa Ethereum! Mas maganda pa, tulad ng government bonds, paraan ang staking para ipakita ang financial support mo sa mga values mo at sa mundong gusto mong tirhan.

Kapag nag-stake ka ng Ether, ita-assign ito sa isang `validator node` na nagpo-process ng mga transaksyon sa Ethereum. Mas maraming Ether ang na-stake, mas maraming node ang magiging kaya ng Ethereum. Sa mas maraming node, mas nagiging `decentralized` at secure ang Ethereum.

Bilang isang `staker`, ikaw ay nagiging **guardian ng Ethereum!**

Ngayon, tingnan natin nang malalim ang staking mechanics at tuklasin ang isang stress-free at low-cost na oportunidad para simulan ang staking journey mo ngayon.

Kunin mo na ang gear mo, tara na!

# Seguridad ng Blockchain

Ang mga `validator node` ang susi sa isang secure at legitimate na ekonomiya sa Ethereum. Pinoprotektahan nila ang blockchain mula sa `pandaraya`.

Ang pandaraya sa mundo ng blockchain ay parang isang user na nagmamanipula ng balances o gumagawa ng crypto na hindi umiiral. Ang paraan ng Ethereum para pigilan ito ay tinitiyak nitong valid ang bawat transaksyon at walang participant na may kapangyarihan sa iba. Ang fairness na ito, na tinatawag na `credible neutrality`, ay mahalaga. Bakit? Walang gustong maging bahagi ng ekonomiyang puno ng panlilinlang at hindi pagtitiwala; babagsak ito sa huli.

Sa isang malusog na blockchain, may isang layunin ang mga validator node: **magkaroon ng decentralized agreement, sa buong network, tungkol sa state ng blockchain.** Sina-scan ng mga node ang mga transaksyon, ini-check ang mga ito laban sa history ng blockchain, at bumoboto kung valid ang mga ito. Ang mga transaksyong pumasa sa `consensus` ng node bilang valid ay idinaragdag sa blockchain.

# Proof-of-Stake

Kailangang mag-lock ng hindi bababa sa 32 ETH ng mga gustong magpatakbo ng `validator node`, at malaking pera iyon. (Simula 2025, puwede nang mag-hold ang iisang validator ng mas malaking balance, at puwedeng lumabas anumang oras ang mga staker sa pamamagitan ng isang queue.) Kapalit ng paglalagay ng malaking financial "stake" sa network, pinapayagan ang `node operator` na mag-propose at mag-review ng mga block ng transaksyon sa Ethereum, at kumita ng rewards. Isipin ang mga block bilang mga grupo ng transaksyong isinumite sa network.

Random na pinipili ng `consensus mechanism` ng network ang isang validator node para i-propose ang susunod na block, at dinodoble-check ng ibang node ang desisyon nito para matiyak ang katapatan. Kapag matagumpay na nag-propose ng block ang isang node, lumalaki ang `stake` nito.

![](https://app.banklessacademy.com/images/staking-on-ethereum/proof-of-stake-49c358ed.svg)

# Slashing

Kapag napatunayang nandaraya ang isang node, tulad ng pag-sign ng dalawang magkasalungat na block, na-slash ang stake nito: mawawalan ito ng bahagi ng Ether nito. Ang pagiging mabagal o offline ay hindi `slashing`; maliit lang na parusa ang gastos doon. Sa ganitong paraan, ang na-stake na Ether ay nagiging security deposit kung saan naiinsentibuhan ang mga node na maging tapat at panatilihing maayos ang takbo ng Ethereum.

Para maaprubahan ng isang attacker ang pandaraya sa Ethereum, kailangan nilang kontrolin ang mayorya ng mga validator node, at kasama na rito ang na-stake na Ether. Sa kabutihang-palad, hindi ito puwedeng mangyari kung sangkot ang mga ordinaryong user sa staking. Hinahati ng `desentralisado` na pagmamay-ari ng network ang kapangyarihan sa paggawa ng desisyon.

![](https://app.banklessacademy.com/images/staking-on-ethereum/slashing-ccabe137.svg)

# Pagpapatunay ng mga Transaksyon

Alamin natin nang sunod-sunod kung paano nagkakasundo ang mga node gamit ang `Proof-of-Stake` consensus:

1. **Staking:** Nag-lock ang isang `node operator` ng 32 ETH sa network at nagsisimulang magpatakbo ng `validator node`.
2. **Block Building:** Isinusumite ng mga user ang mga transaksyong inayos sa mga `block` ng mga `block builder`.
3. **Proposer Selection:** May algorithm na pumipili ng validator node para i-propose ang susunod na block na idaragdag sa blockchain.
4. **Block Proposal:** Rine-review ng `block proposer` ang mga posibleng block at pumipili ng isa, na nagbibigay ng `attestation` kung valid.
5. **Cross-Verification:** Dinodoble-check ng ibang validator ang block at nagbibigay ng attestation kung valid. Basta na lang binabalewala ang mga invalid na block at hindi sumasama sa chain.
6. **Block Addition:** Idinaragdag sa Ethereum blockchain ang valid na block.
7. **Rewards:** Kumikita ang block proposer ng `block reward` at transaction tips. Napapala rin ang ibang validator.

# Ethernomics

Sa pagbibigay ng Ether sa isang validator node, kumikita ang mga staker ng bahagi ng rewards nito.

Ang rewards na natatanggap ng mga node ay base sa iba't ibang ecosystem factor at puwedeng magbago. Sa madaling salita, ang rewards ay bahagi ng mga transaction fee at kaunting bagong-issue na Ether na idinaragdag sa mga bagong block.

Nag-iiba-iba ang annual yield sa paglipas ng panahon, kasaysayan namang ilang porsyento lang ng na-stake na Ether. Base ang eksaktong halaga sa dalawang pangunahing factor:

- 📈 **Network Activity:** Sa pangkalahatan, kung mababa ang traffic, mas mababa ang rewards. Kung mataas ang traffic, mas mataas ito.
- 👥 **Bilang ng Validator Node:** Mas nahahati ang rewards sa mas maraming participant.

Nagbabago rin ang yield depende sa paraan mo ng pag-stake ng Ether mo. Tingnan natin ang mga option natin.

# Mga Uri ng Staking

Karaniwang kailangan mong mag-lock ng 32 ETH para magpatakbo ng `validator node`, pero ginawa ng mga bagong staking method na available sa lahat ang pagbabantay sa Ethereum.

Kaya, may tatlong paraan para protektahan ang Ethereum:

- 📡 **Solo Staking:** Magpatakbo mismo ng validator node.
- ⛲ **Staking Pools:** Sumali sa grupo ng mga staker at sama-samang magpatakbo ng node.
- 🏦 **Centralized Exchange Staking:** Sumali sa isang node ng "crypto bank".

Nangangailangan ang bawat method ng iba't ibang antas ng technical na kaalaman para ma-set up, kasama ang sarili nitong risks.

Kung kumportable ka sa pag-hold ng `private key` mo pero wala kang 32 ETH, isaalang-alang ang pagsali sa iba sa isang staking pool.

Kung hindi ka pa komportable sa pagkuha ng `self-custody` ng crypto mo, tingnan ang Centralized Exchange staking. Sa ngayon, kunin ang [Wallet Basics](https://app.banklessacademy.com/lessons/wallet-basics) lesson namin at buong-tapang na angkinin ang pagmamay-ari ng crypto mo!

# Sentralisasyon ng Network

**Ang anumang staking na nagreresulta sa maraming node sa ilalim ng isang entity ay nagsisimulang mag-centralize sa Ethereum.**

Isipin ang Ethereum bilang isang web ng magkakakonektang `validator node`. Kapag nagkonsentra ang mga node sa ilalim ng iisang entity, nagiging imbalanse at hindi safe ang buong web. Kailangan natin ng maraming natatanging connection point.

Masamang senyales kung may makakuha ng kontrol sa sapat na bilang ng node: mapipilitan ang mga block na dumaan sa centralized na bahagi ng web. Puwede nitong aprubahan ang mga fraudulent na block, o tanggihan ang mga valid. Wawasakin nito ang `credible neutrality` ng Ethereum.

Bilang mga guardian, dapat tayong mag-focus sa staking method na nagpapanatiling `desentralisado` ang web.

Mahirap patakbuhin ang sarili mong validator node bilang beginner, kaya tuklasin natin ang isang beginner-friendly na option: ang mga `staking pool`.

![](https://app.banklessacademy.com/images/staking-on-ethereum/network-centralization-0622ba07.svg)

# Mga Staking Pool

Ang pinakamagandang bahagi ng mga `staking pool` ay pinapatakbo ito nang buo ng mga `smart contract`. Hindi mo kailangang makilala nang personal ang ibang staker o magtiwala sa kanila, kundi sa smart contract lang.

Inoorganisa ang mga staking pool ng mga `staking provider`, mga digital platform na nagkokonekta sa mga staker sa buong mundo! Rito, nag-i-stake ang isang `node operator` ng bahagi lang ng 32 ETH at siya ang nagpapatakbo ng node, habang ang natitira ay galing sa ibang participant, kapalit ng extra yield.

Binibigyan ang ibang participant ng "Liquid Staking Tokens" (LSTs) na katumbas ng membership nila sa pool. Kumakatawan ang mga `token` na ito sa isang share ng na-stake na Ether, kumikita ng bahaging katumbas nito, at puwedeng i-redeem anumang oras.

Sa pag-hold lang ng isang LST (tulad ng rETH ng Rocket Pool), meron kang share sa isang staking pool: dine-decentralize ng Ether mo ang Ethereum habang kumikita pa!

![](https://app.banklessacademy.com/images/staking-on-ethereum/staking-pools-46c96251.svg)

# Liquid Staking Tokens

Ang pinakamagandang bagay tungkol sa mga `LSTs` ay habang naka-stake at kumikita ng yield ang Ether mo, nananatili itong `liquid`.

Ang ibig sabihin ng "liquid" dito, puwede pa rin itong umagos sa buong ecosystem. Isipin ang pag-hold ng share sa isang staking pool… pero puwede mo itong gamiting parang pera! Puwedeng i-swap ang mga LST, gamitin bilang collateral sa loans, o kahit i-deposit sa mga `restaking` platform, isang optional na estratehiyang nagdaragdag ng risk kapalit ng extra yield.

Maganda ang mga LST dahil binubuksan nila ang access sa na-stake na Ether. Kadalasang may minimum deposit amount ang mga staking pool para makapagdagdag ng Ether sa pool (mga 0.01 ETH). Pero sa paggamit ng LST, puwede kang bumili ng mas maliliit na increment ng na-stake na Ether sa paborito mong `decentralized exchange`.

# Sentralisasyon ng Network, Muli!

Parehong may bitag ang staking pools at LSTs na tulad ng ibang staking method: **gumagana sila sa iba't ibang antas ng sentralisasyon at desentralisasyon.**

Tiniyak ng mga staking provider tulad ng Rocket Pool na sinuman, saanman, ay puwedeng maging `node operator` ng isang staking pool, na tumutulong ma-decentralize ang Ethereum. Pero may ibang provider na iilan lang sa mga kontak nila ang pinapayagang magpatakbo ng node, kaya nagiging risk ang sentralisasyon ng na-stake na Ether.

Kung magkaroon ang anumang entity ng higit sa 33% na kontrol sa lahat ng na-stake na Ether, puwede itong magdulot ng problema sa network. Sa 50%, seryosong pinagbabantaan nito ang `credible neutrality` ng Ethereum.

May ilang malalaking staking provider nang nalapit sa 33% na iyon. Ang pagkalat ng stake sa maraming provider ang nagpapanatiling safe sa network.

Kailangan nating mag-research para bantayan ang Ethereum. Kahit sa mga `staking pool`, kailangan nating gumawa ng mga desisyong sumusuporta sa desentralisasyon.
